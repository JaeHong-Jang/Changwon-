# data/raw — 원본 데이터

수집한 원본 데이터를 이 폴더에 저장합니다.

## 규칙
- **원본 데이터는 절대 수정하지 않습니다.**
- 파일명 형식: `{출처}_{데이터명}_{수집일}.{확장자}`
  - 예: `datagokr_창원시_교통사고_20260701.csv`
- 대용량 파일은 `.gitignore`에 의해 git에 올라가지 않습니다.
- 데이터 출처와 다운로드 URL을 아래 표에 기록해 주세요.
