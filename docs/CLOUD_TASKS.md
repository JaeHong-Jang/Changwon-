**논문 방향 (NHESS 1순위):** "평가 설계가 판정을 뒤집는다 — 행정 침수흔적 10사상으로 지침형 도시 침수지수를 감사하는 규약".

- 논의·부록으로 내림: CDRI, 예보.

**현재 수치 (전부 재현 검증됨, `Q1_verify.md`):**

- 사상별 시간순 평가: `artifacts/posthoc/20260926/walkforward_20260926T135215Z_3d14fc1/`.
- 설정 강건성·설명: `artifacts/posthoc/20260926/robust_20260926T135911Z_3d14fc1/`.

**자료 (100 m 격자 75,400칸):**
- 개발 사상: 2006, 2012, 2014, 2016, 2019 (행안부 API), 2025 (시).

**절차 고정:** 각 과제는 계산 전에 절차(점수·배경·판정 규칙)를 `docs/q1/<ID>_protocol.md` 로 먼저 커밋한 뒤 실행한다.

## 과제

### M1 자명한 기준선과 어려운 음성 (3~5일, 새 자료 불필요) — 가장 먼저
- **목표:** "지형 모형이 잘 맞힌다"가 단순한 산지 대 평지 구분 이상인지 판정한다.
- **점수:**
  - 경사 단독(−), 상대고도 단독(−), TWI 단독, 불투수 단독, HAND
    - HAND: 90 m DEM 과 하천망으로 계산한다. 기존 `fill_sinks`·`flow_accumulation` 을 재사용한다.
  - 비교 대상: L1, `z_sensitivity`, RF-F1(이전 사상 학습), 로지스틱.
- **배경:**
  - 전 격자
  - 평지만: 경사 임계를 계산 전에 고정한다
  - 토지피복별: 시가지·농경지
  - 인구 거주 격자(universe) 안: H 단독 AUC
- **단위·지표:** 사상별 시간순(`walkforward.py` 패턴). 격자 AUC·상위 20% 포착과 객체 AUC.
- **사전 판정 규칙:** 경사 단독의 사상별 AUC 중앙값이 RF 와 0.02 이내면 C-b(지형 모형 우위) 주장을 폐기한다.
- **산출:** `artifacts/q1/M1/<run_id>/`, `docs/q1/M1.md`
- **자료:** 토지피복 원본은 cloud-base 에 없다. 격자 토지피복 층화가 필요하면 가공 스냅샷의 특징(`impervious_frac` 등)이나 흔적 속성으로 정의하고, 그 정의를 절차 문서에 적는다.

### M2 사상 단위 보고 (2~3일)
- 유효 표본을 사상으로 명시한다.
- 사상별 AUC 를 무작위효과로 통합한다. logit AUC 와 부트스트랩 SE 를 쓰고 이질성 I² 를 보고한다.
- 개발과 홀드아웃을 분리한다.
- 대상 점수는 M1 과 같다.

### M3 중첩 시간순 교차검증 (1주)
- 각 시험 사상마다, 그 이전 사상 안에서만 LOEO 로 특징집합(F0/F1/F2)과 하이퍼파라미터(`.omc/benchmark/prespec.json` 격자)를 고른다.
- 고정 구성 walk-forward 와 비교한다.
- 이전 사상이 1개뿐인 행은 "선택 불가"로 표기한다.

### M4 라벨 규칙 × 격자 크기 민감도 (1~2주) — C-c 핵심
- **규칙:** 교집합 > 0, 1%, 10%, 25%, 50%, 중심점, 면적가중 연성 라벨.
- **격자 크기:** 100·200·500·1000 m (100 m 특징을 집계한다. 100 m 미만은 DEM 90 m 한계로 제외한다).
- **측정:**
  - 점수별 판정이 뒤집히는 규칙과 크기 (게이트 통과 여부, 순위)
  - 객체 크기 구간별 생존율
- **해석적 분해:** "격자 AUC = 객체 기여의 가중평균"을 유도하고 수치로 확인한다.
- **기존 모듈:** `src/data/trace_labels.py`, `src/models/label_audit.py`.

### M5 사전 고정 다도시 재현 — **생략 (2026-09-27 사용자 결정)**
- **생략 이유:**
  - M1 에서 post-hoc 주장(C-b)이 폐기됐다.
  - 남은 핵심은 사전 고정 결과(L1 게이트 탈락, 32개 설정에서 유지)와 수학적 분해(M4)다.
  - 그래서 단일 도시 사례 연구로 쓴다. 단일 도시 Q1 선례: `docs/research_reports/Q1_literature.md`.
- **이미 한 것:** 단계 A 절차(`docs/q1/M5_protocol.md`, 커밋 f80f736)는 기록으로만 남긴다. 등록하지 않았고 실행하지 않았다.
  논문에 다도시 재현을 주장하지 않고, 한계 절에 적는다.
- 아래 원래 정의는 참고용이다.

### M4S 분해식의 일반성 — 가상 자료 시연 (1~2일, 새 자료 불필요)
- **목표:** M4 의 "격자 AUC = 객체 기여의 가중평균" 분해와 가중치 집중 현상이 창원 자료에만 있는 성질이 아님을 보인다.
- **가상 인벤토리:** 객체 크기 분포(로그정규 등), 사상 수, 사상별 객체 수, 점수–객체 관계를 바꿔 만든다.
- **측정:**
  - 격자 AUC 와 객체 AUC 의 차이
  - 크기 가중·소실 성분
  - 유효 객체 수
  - 게이트 판정이 바뀌는 조건
- **재사용:** `src/data/validation/decomposition.py`, `weighted_auc.py`.
- **판정 규칙은 계산 전에 적는다:** 어떤 조건에서 격자 AUC 가 객체 AUC 와 0.1 이상 벌어지는가.
- **산출:** `artifacts/q1/M4S/<run_id>/`, `docs/q1/M4S.md`

#### (참고용) 원래 M5 정의

**단계 A (결과를 보지 않는다):** 절차 문서를 쓴다.
- **도시 선정 규칙:** 행안부 API 에서 날짜 있는 흔적의 연도 수 ≥ 5 와 폴리곤 수 기준을 쓰고, 창원은 제외한다.
  - 참고로 `api_scan_summary.json` 에서 50110·48270·50130 이 다년 도시다. 그래도 규칙으로 고른다.
- **입력:** 전국 공통 공개자료만 쓴다: Copernicus GLO-30 DEM, ESA WorldCover, OSM 하천.
- **변수·점수·평가 규약:** M1·M4 와 같게 한다.
- **가설:** 방향을 명시한다.
- 절차 문서를 커밋하고 해시를 기록한다. OSF/Zenodo 등록은 사용자가 한다.

**단계 B:** 등록 해시가 생긴 뒤 수집과 평가를 한다.
- 필요: `SAFETYDATA_API_KEY`, 클라우드 네트워크 접근.
- 창원 코드(`src/data/safetydata.py` 등)를 도시 코드 인자로 일반화한다. 새 파일로 만든다 (§6).
