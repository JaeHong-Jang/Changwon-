### A1. 🏙️ 창원특례시 도시침수정보시스템 침수예상도 WFS/WMS ✅

- **URL**: `https://bangjae.changwon.go.kr/geoserver/cw/wfs?service=WFS&version=1.1.0&request=GetFeature&typeName=cw:L210_100&outputFormat=application/json`
- **접근**: 인증 없이 직접 다운로드 (WFS GetFeature, `maxFeatures`+`startIndex` 페이징, `resultType=hits` 지원)
- **형식·단위**: GeoJSON/GML MultiPolygon, **EPSG:5181**; 침수심 등급 폴리곤(원자료 ~10m급 추정), 빈도별 정적 시나리오, 작성연도 2024
- **확인한 내용**: 13개 레이어 건수 전수 확인 — 홍수범람 L200_050/080/100/200 (27,478/28,240/28,544/31,529), 내수침수 L210_030/050/080/100 (37,359/39,186/40,494/41,130), 해안침수 L220_050/100/150/200 (2,290/2,681/3,120/3,306), 재해정보지도 L300 (62,430). 속성 `F_SHIM`('~0.5','0.5~1.0','1.0~1.5','1.5~2.0','2.0~3.0','3.0~'), `F_AREA`(㎡), `ADM_CD`(4812x 구 코드), `WRT_YR`=2024. L300은 `AMD_CD`(오타 그대로), `IDX_NM/IDX_CD` 등 필드 상이.
- **레이어**: L1 핵심(내수침수·홍수범람 침수심 → 100m 격자 면적가중 집계) / 검증 타깃 / L2(내수침수 예상구역 × 관로 민원 교차)
- **왜 필요한가**: 국토부 지침의 "침수예상도" 활용 근거를 창원시 공식 산출물로 충족. 침수흔적도 SHP 미수령 시 L1 검증 타깃 대체.
- **주의**: 공식 개방데이터 아님(시스템 내부 GeoServer) → 보고서에 출처·취득일 명시, 요청 간격 조절. 한글 속성(`FEXMP_NM`) latin1→cp949 재디코딩. 원 산출 모델·강우 시나리오 문서 없음(자연재해저감종합계획 부속 추정 → 정보공개청구로 설명서 요청). 좌표 5181→5179/4326 변환.
