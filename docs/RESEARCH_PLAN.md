## 0. 하네스 구조란

이 계획은 "할 일 목록"이 아니라 **증거 게이트로 연결된 스토리 체인**입니다.

```
Story N  ──[증거 제출]──▶  checkpoint  ──▶  Story N+1 활성화
              │
              └─ 증거 없으면 완료 불가 (goals.py가 거부)
```

| 원칙 | 구현 |
|------|------|
| 각 스토리 = 목표 + 입력 + 산출물 + **검증 기준** | 이 문서 §4 |
| 다음 스토리는 이전 스토리 checkpoint 후에만 시작 | `goals.py next` |
| 완료 주장에는 반드시 증거(파일 경로·수치·로그) | `goals.py checkpoint --evidence` |
| 결정은 기록으로 남김 | `docs/decisions/NNN-*.md` |
| 분기점(Decision Gate)은 증거 기반으로 Plan A/B 선택 | G006 |
| 최종 스토리는 검증 명령 없이 완료 불가 | `--verify-cmd` 게이트 |
| 상태는 파일로 영속화 → 세션·사람이 바뀌어도 이어감 | `.fablize/goals.json` + git |

**운영 명령**
```bash
# 저장소 루트에서
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py status      # 현재 상태
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py next        # 다음 스토리 활성화 + 핸드오프 출력
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py checkpoint --id G00N --status complete --evidence "..."
```
> Windows 팀원: `python C:\Users\User\.claude\plugins\fablize\scripts\goals.py ...` (경로만 다름)

### 1-2. 방법론

| 발견 | 계획 반영 |
|------|----------|
| **국토부 「도시 기후변화 재해취약성분석 지침」**: 취약성 = 기후노출 × 도시민감도, **100m 격자**(2024 개정), Jenks I~IV | Layer 1·3을 이 구조로 → "창원시 실무와 동일 표준" = 정책 실현성 근거 |
| **IPCC AR5**: Risk = Hazard × Exposure × Vulnerability | 통합 지수 수식 |
| **창원시 선행연구 2편** (최유라·한우석 2024 국토연구; 박기용 외 2017) — 검증 사례지: 마산회원구 양덕동·봉암동, 의창구 팔용·명서·사화동, 동읍 덕산리 | Layer 1 검증용 ground truth + "선행연구는 도시계획 관점, 격자 예측·AI 결합은 공백" 차별화 |
| 가중치: 실무 표준은 표준화 후 합산(동일가중), 학술 차별화는 엔트로피 (이선미 외 2020) | 기본 동일가중 + 엔트로피 민감도 분석 → "가중치에 강건" 주장 |
| 등급: Balica(2013) 5등급 (음정인·김형규 2024) | 최종 등급 체계 |
| 관로노후×강우→민원 ML은 **학술 공백** | Layer 2 Plan A의 독창성 근거 |

### 1-3. 수상작 패턴

| 발견 | 계획 반영 |
|------|----------|

| 2026 공식 서식 목차: 개요 → 데이터·툴·알고리즘·**스토리보드** → 해석 → 활용·기대효과 → 출처 | 보고서 장 제목을 그대로 따름. Agent 화면 흐름 = 스토리보드 |
| 권장 배분 16~19매, 지도 6~8장, 표 4~6개 | G013 체크리스트 |

## 2. 연구 설계 (확정)

### 2-1. 연구 질문
> 폭우 시 창원시에서 **침수·하수 역류 위험이 높고 취약계층이 밀집한 격자**는 어디이며, AI Agent가 이를 **선제 알림·민원 초동대응**으로 어떻게 연결할 수 있는가?

### 2-2. 분석 프레임 — 국토부 지침 + IPCC AR5

```
공간 단위: 100m 격자 (국토부 2024 개정 지침 준수, SGIS 격자인구와 직접 결합)

Layer 1  침수 취약성  = 기후노출(강우 IDW 보간) × 민감도(저지대·경사·불투수면·하천버퍼·펌프장거리)
Layer 2  역류 위험    = Plan A: 관로 경과연수·관경·재질·밀도 + 강우 → XGBoost(타깃=민원) + SHAP
                       Plan B: 처리구역 합류식비율 × 관로밀도 × 동별 민원건수 → 노후도 점수 (rule-based)
Layer 3  취약계층     = 65세↑·1인가구(SGIS) + 노후건물·지하층(건축HUB) − 적응역량(대피소·펌프장 접근성)

통합     CDRI = Hazard(L1+L2 정규화) × Exposure(인구밀도·건물수) × Vulnerability(L3)
         → 0~1 정규화 → Balica 5등급 → TOP 20 격자 + 기여도 분해(침수/역류/취약 %)
가중치   기본 동일가중(지침) + 엔트로피·AHP 민감도 → 순위 상관(Spearman) 보고
검증     Layer 1: 선행연구 사례지 5곳 + 시민의소리 침수 민원 위치 적중률
         Layer 2: (A) 홀드아웃 F1/AUC + SHAP  (B) 민원 상위 동과의 순위 상관
```

### 2-3. AI Agent (정량 효과 중심)

| Agent | 트리거 | 도구(tool) | 출력 | 측정 지표 |
|-------|--------|-----------|------|----------|
| 재난 감시 | 기상청 특보 API 폴링 | `get_forecast`, `query_grid_risk`, `draft_alert` | "○○동 격자 위험 1위, 펌프 선제 가동 권고" 담당부서 알림 초안 | 특보→알림 생성 소요시간(분) |
| 민원 분류 | 민원 텍스트 입력 | `extract_location`, `classify_type`, `query_grid_risk` | 위치·유형·긴급도 + 하수센터 배정 | 수동 분류 대비 시간 단축(%) |
| 시민 안내 | 시민 질의 | `query_grid_risk`, `nearest_shelter` | 우리 동네 위험도 + 대피소 + 행동요령 | 시나리오 응답 정확도 |

구현: Claude API tool use + Python 함수 3~5개 + Streamlit 데모. **시나리오 3개** 실행 로그·화면을 스토리보드로 제출.

**G007 Layer 1 침수 취약성** — R1 · 9/8

- 검증 세트: 선행연구 사례지 5곳(양덕·봉암·팔용·명서·사화) + 시민의소리 침수 민원 위치
- 산출물: `data/processed/layer1_flood.gpkg`, `reports/figures/layer1_map.png`
- **검증**: 사례지 5곳 중 I·II등급 적중 수, 민원 위치 상위 20% 격자 포함률 (AUC 또는 적중률 수치)

**G008 Layer 2 역류 위험** — R2 · 9/12

- Plan B: 처리구역 합류식비율 × 관로밀도 × 동별 민원건수 → 0~1 점수
- 산출물: `data/processed/layer2_sewer.gpkg`, `reports/figures/layer2_map.png` (+ A: SHAP summary)
- **검증**: A → 홀드아웃 F1·AUC 표 / B → 민원 상위 10개 동과 점수 상위 동 Spearman ρ

**G009 Layer 3 취약계층** — R1 · 9/10
