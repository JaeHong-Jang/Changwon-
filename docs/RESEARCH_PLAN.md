## 1. 연구 제목 및 요약

**국문**: 창원시 폭우 침수·하수 역류 우선 대응지역 분석 — 100m 격자 통합위험지수(CDRI, **창원 배수인프라 위험지수**) 기반 TOP 20 선정
**영문**: Prioritizing Pluvial-Flood and Sewer-Backflow Response Areas in Changwon: A 100 m Grid **Changwon Drainage-Infrastructure Risk Index (CDRI)** for Selecting the Top 20 Grids

**요약**: 창원시 강수·하천수위·배수펌프장·하수관로·민원·인구·건물 데이터를 100m 격자로 결합해 침수 취약성(L1)·하수 역류 위험(L2)·취약계층(L3)을 IPCC AR5 위험 프레임(Risk = Hazard × Exposure × Vulnerability)과 국토부 재해취약성분석 지침 구조로 통합한 CDRI를 산출하고, 폭우 시 먼저 점검·대응할 격자 TOP 20과 그 이유(침수/역류/취약 기여도)를 제시한다. 민원 원문은 LLM으로 구조화해 L2의 라벨·검증에 쓰고, 가중치 3안·집계 2안·해상도 민감도와 침수흔적도 ROC-AUC로 결과의 강건성을 검증하며, 결과는 R1~R5 등급과 부서별 대응 행동표로 하수도사업소·재난안전 부서의 점검 순서에 연결한다.

## 2. 연구 배경 및 필요성

**2-1 창원의 침수·하수 문제 (수치)**
- 창원시 도시지역 462.14㎢(시 748.81㎢의 61.72%) 중 침수피해지역 11.03㎢, 하천범람취약지역 18.34㎢, 두 지역의 중첩 취약지역 0.92㎢(공업지역 0.48㎢, 52.14%)이며, 마산회원구 양덕동·봉암동, 의창구 팔용·명서·사화동, 동읍 덕산리 등은 하수관거 확충에도 저지대·복개천·해수 역류로 반복 침수한다(최유라·한우석, 2024).
- 창원시 재난안전대책본부 침수흔적도 게시판에는 2020~2023년 사상 69건(태풍 카눈·힌남노·오마이스·마이삭·하이선, 2021.7 집중호우)이 지구별로 남아 있고, 예컨대 내동지구(2023.8.10)는 침수 6h·침수면적 20,164㎡·원인 "내수배제 불량"으로 기록되어 있다(DATA_CATALOG A2).
- 환경부 하수도통계 2025년판 기준 창원시 하수관로 총연장 3,958,862.72m, 보급률 95.6%, 하수도 민원 연 7,135건(하수관로 2,391·배수설비 2,019·맨홀 1,336·악취 599·기타 790)이다(DATA_CATALOG A9). 관로 상태는 경과연수·재질·관경에 좌우되고(Malek Mohammadi et al., 2020) 막힘은 공간적으로 군집하며(Okwori et al., 2021), 통수능 부족은 강우 시간분포와 결합해 내수침수로 이어진다(이재현 외, 2021).
- 배수(하수)시설은 도시침수의 핵심 조건 인자이며 이를 침수 모델에 넣으면 정확도가 유의하게 오른다(서울 사례, 배수 변수 2개 추가로 정확도 +7.58%p, AUC +3.80%p; Bersabe & Jun, 2025). 침수와 하수 역류를 **한 지수로** 다뤄야 할 근거다.

**2-2 정책 맥락**
- 창원시는 제2차 자연재해저감종합계획(안, 2022.11)에서 위험지구 115개소(하천 33·**내수 13**·사면 32·토사 17·해안 10·대설 7·기타 3)를 지정했고, 1차 계획(2015) 130개소의 정비율은 43.8%다(DATA_CATALOG A4). 2025년 인명피해우려지역 238개소 중 침수취약시설 58개소는 집계만 공개되어 개별 위치는 없다(A3). 하수도정비기본계획(변경) 용역(2024.6~2026.3)은 미공개다(DATA_CATALOG §5).
- 하수도사업소(3개 하수센터, 78억 하수도 정비 예산)와 재난안전대책본부 폭우 TF가 2차 심사에 직접 참여한다 → 결과물이 **기존 사업의 점검 순서**로 곧바로 들어가야 한다. 「하수도법」 제4조의3(하수도정비중점관리지역의 지정 등) 지정 요청의 근거자료로도 연결 가능하다.
- 창원특례시는 자체 도시침수정보시스템(침수예상도 WFS 13레이어, 대피장소 API)을 운영해 격자 분석 입력을 시 공식 산출물로 충족할 수 있다(A1·A5).

**2-3 왜 지금, 왜 격자인가**
- 국토부 「도시 기후변화 재해취약성분석 지침」이 2024년 개정으로 **100m 격자**를 표준 단위로 채택했다(국토교통부, 2024; 배경: 한우석 외, 2024). 창원시 실무와 동일 표준을 쓰는 것이 정책 실현성의 근거다.
- 집계 단위가 커질수록 고취약 인구를 과소집계하고(Hinojos et al., 2023), 집계구보다 격자가 세부 결과를 준다(홍재주 외, 2015). 다만 하천 인접 격자의 Ⅰ등급 과다라는 격자 분석의 한계도 보고되어(최유라·한우석, 2024 재인용) 하천 변수 제외 민감도 분석이 필요하다.
- SGIS 100m 격자 인구가 존재해 노출·취약계층을 같은 단위로 결합할 수 있고(E7), 홍수취약성지수 95편 중 민감도 분석 9.5%·외부 검증 13.7%에 그친다는 지적(Moreira et al., 2021 NHESS)은 검증 설계를 갖춘 격자 지수의 여지를 보여준다.

## 3. 연구 목적 및 연구 질문

**목적(1문장)**: 폭우 시 창원시에서 침수·하수 역류 위험이 높고 취약계층이 밀집한 100m 격자를 통합위험지수(CDRI)로 식별하여, 우선 점검·대응 지역 TOP 20과 그 원인(기여도)을 하수도사업소·재난안전 부서가 쓸 수 있는 형태(R1~R5 등급·대응 행동표)로 제시한다.

**연구 질문**
- **RQ1 (Layer 1)**: 강우 노출과 지형·불투수·배수 조건을 100m 격자로 결합한 침수 취약성 지수는 실제 침수 발생 위치(침수흔적·사례지·침수 민원)를 얼마나 구분하는가?
- **RQ2 (Layer 2)**: 하수관로 노후·밀도와 강우 조건은 격자 단위 역류·막힘 민원 발생을 얼마나 설명하며, 어떤 요인의 기여가 큰가?
- **RQ3 (통합)**: L1·L2·L3를 H×E×V로 통합한 CDRI의 상위 격자는 가중치·집계·해상도 선택에 강건한가, 시가 이미 지정한 위험지역은 CDRI에서 높은가, 그리고 어디가 새로 드러나는가?

**가설(검증 가능한 형태, 사전 고정·사후 조정 금지)**
- **H1**: L1 지수는 침수흔적 격자를 ROC-AUC ≥ 0.70으로 구분하고(양성 격자 ≥30일 때만 AUC 보고; <30이면 AUC 대신 사례지 lift·상위 20% 포착률만 보고), 선행연구 사례지 5개 동(양덕·봉암·팔용·명서·사화)의 I·II등급 lift ≥ 1.5, 침수형 민원 AUC ≥ 0.65를 보인다. 여기서 **lift = (사례지 격자 중 I·II등급 비율) / (유니버스 I·II등급 비율)**, **I등급이 최취약**이다. 동읍 덕산·용전·남산리는 하수처리구역 밖·농촌형으로 유니버스 밖이 대부분이므로 **별도 보고(제외 사유 명시)**한다.
- **H2**: (Plan A) 관로 경과연수·관경·재질·밀도 + 강우 피처의 XGBoost는 행정동 GroupKFold 공간 CV에서 PR-AUC ≥ 양성비×2, ROC-AUC ≥ 0.70을 달성하고, **mean|SHAP| Top5 안에 경과연수·30년↑비율·관경 중 1개 이상**이 포함된다. (Plan B) **민원 항목을 제외한 '노후율×관로밀도' 점수**와 동별 민원 순위의 Spearman ρ ≥ 0.4이며, 자연재해저감종합계획 내수 위험지구 13개소 격자의 L2 백분위 중앙값 ≥ 70이다.
- **H3-a (강건성)**: CDRI 순위는 가중치 3안(동일·엔트로피·AHP) 간 전 격자 Spearman ρ ≥ 0.9·TOP 20 겹침 ≥ 14, **집계 2안(기하 vs 가법) 간에도 ρ ≥ 0.9·TOP 20 겹침 ≥ 14**, 500m 재집계 ρ ≥ 0.8이다.
- **H3-b (타당성·신규성)**: 시 지정 위험지역(A3 침수취약시설 58·A4 내수 위험지구 13·A14 재해위험지구) 격자의 **CDRI 백분위 중앙값 ≥ 70**이고, **TOP 20 중 미지정 격자 ≥ 5곳**이다.

**최종 산출물 정의**: ① TOP 20 격자 표(격자ID·행정동·도로명/랜드마크·CDRI·grade_raw·grade_final·기여도 침수/역류/취약 %·주 원인·최근접 펌프장/하수센터·인구·65세↑·지하층 건물·3년 민원·시 지정 여부) ② 유니버스 전 격자의 **R1~R5 등급 지도(본안 + 1안 Balica·2안 Jenks 병기)** ③ 레이어별 지도·민감도 표·검증 표 ④ 등급별 대응 행동표 + 부서별 3개월 시범 점검안.

## 4. 선행연구 검토 및 차별성

**4-1 도시침수 취약성 격자 평가**: 국토부 지침(2024)의 취약성=기후노출×도시민감도, z-score 표준화→합산→Jenks I~IV 매트릭스가 국내 실무 표준이며, 격자 전환의 원류는 홍재주 외(2015)다. 서울 격자 취약성 지도를 침수 이력으로 검증해 AUC 84.37%를 얻은 강정은·이명진(2012), 관측소 시간강수 95퍼센타일 보간×불투수면 지수의 노윤진 외(2025), 배수분구 회귀에서 최대 시간강우강도·완경사·주상혼재가 침수를 설명한다는 신상영·박창열(2014), 지표(MCDM)와 ML을 비교한 Khosravi et al.(2019), 시간 분할 검증의 Lee et al.(2017)이 L1 변수·검증의 근거다. 지표기반 평가는 종합취약성 파악에 적합하나 침수심은 산정하지 않는다(Nasiri et al., 2016).

**4-2 하수관로 노후·역류 예측**: 관로 상태의 핵심 인자는 age·material·diameter·length(Malek Mohammadi et al., 2020)이며 환경·운영 인자를 결합한 연구는 드물다(Hawari et al., 2020). 국내 CCTV 자료 기반 Weibull 노후도(강병준 외, 2020), 위험도 기반 CCTV 조사 우선순위(손주영 외, 2017), 막힘의 공간 군집·RF 예측(Okwori et al., 2021), 보고타 하수관망 고장위험 2단계 시공간 ML(Fontecha et al., 2021), XGBoost-SHAP 침수 인자 정량화(Wang et al., 2023; Lundberg et al., 2020)가 Plan A/B의 틀이다. **관로 노후 속성 × 강우 → 역류 민원을 타깃으로 학습한 사례는 학술적으로 비어 있으며(Hawari et al., 2020의 지적), 이것이 Layer 2 Plan A의 독창성 근거다.** 311 민원을 도로침수의 대리변수로 쓴 Agonafir et al.(2022a, 2022b), 국내 민원 텍스트 마이닝 선례(김현종 외, 2018), LLM 주석의 정확도(Gilardi et al., 2023)가 민원 LLM 구조화의 선례다.

**4-3 사회적 취약성·통합지수**: SoVI(Cutter et al., 2003; 김강민 외, 2024), 취약계층이 침수위험지에 더 거주한다는 국내 결과(서정석·한우석, 2019), 고령자 보행 5분 300m 대피소 서비스 영역(박재국·김동문, 2012), 노인·노후건물이 많을수록 대피시설이 멀다는 '취약계층 밀집지의 대피 접근성 열악' 논지(박현수·권설아, 2022), 건축물 정보 기반 침수 취약성(이은석, 2020)이 L3의 근거다. 통합은 복합지수 10단계(OECD/JRC, 2008), FVI 0~1 정규화·무가중 원칙(Balica et al., 2012), 승법 집계 권고(Choi, 2019), 계층형 설계(Tate, 2012), 정규화·집계·등급화 민감도 프로토콜(Moreira et al., 2021 Water), 가중치가 순위 불확실성의 58%라는 국내 33개 도시 결과(Ziarh et al., 2024), 엔트로피 가중치(이선미 외, 2020), AHP(Saaty, 1990; 유인상 외, 2025)를 따른다.

**4-4 창원 선행연구·2022 공모전 우수상 → 공백·차별화**: 창원 직접 연구는 최유라·한우석(2024)과 박기용 외(2017)로 모두 도시계획·용도지역 관점이며, 격자 통합지수·취약계층 결합·민원 데이터 활용은 공백이다. 2022 창원 우수상 "침수예측모델(LGBM)"이 존재하므로 1차 "중복 여부" 심사 대응으로 서두에 차별화 표를 둔다. **단, 2022 수상작은 LITERATURE §4의 '원문 확인 후 인용' 원칙 대상이므로 아래 표의 2022 열은 원문(창원시 홈페이지·데이터포털 수상작 게시본 또는 정보공개청구 #16 항목 ⑤) 확보·대조 후 G013에서 확정한다.** 수상작 공통 패턴(창원 데이터포털 데이터 + TOP N/최적 입지 + 자체 지수 + 정책 연계, 2차 심사에 관련 부서 참여, 2026 서식 목차 개요→데이터·툴·알고리즘·스토리보드→해석→활용·기대효과→출처, 권장 16~19매·지도 6~8장·표 4~6개)은 §7·G013에 반영했다.

**6-3 Layer 1 침수 취약성 (G007)**: 기후노출 = ① 연최대 시간강수 10년 평균 ② 시간강수 ≥30mm 발생시간 수 ③ 상위 5개 이벤트(2024.9 포함) 3h·24h 누적 ④ 확률강우량 초과비율(①/WAMIS 30년빈도 1h; 하수관로 설계빈도 10~30년 해석은 환경부, 2022 KDS 61 10 00). IDW power∈{1,2,3} LOOCV RMSE 최소 선택, 최근접 12지점·반경 10km, 외삽 금지; **보조로 pykrige 정규 크리깅 LOOCV RMSE 1회 산출, IDW가 ±10% 이내면 IDW 채택**(공간보간 방법 비교: 황석환·함대헌, 2013). 민감도 = 상대고도(500m 초점평균, HAND 병행)·경사·TWI·불투수율(EGIS, 대체 SGIS 건물연면적)·하천 근접 max(0,1−d/300)·내수침수 예상 침수심(WFS L210_100 면적가중)·펌프장 서비스권 1km. 1~99% 윈저라이즈 → z-score → 동일가중 합산 → 각각 Jenks 4등급(Jenks, 1967) → 매트릭스 I~IV(지도용, I=최취약), CDRI 입력 L1=minmax(z합). 원칙: **예상도=입력, 흔적도=검증**. 하천·예상도 제외 민감도 1회 필수(홍재주 외 2015의 Ⅰ등급 과다 대응).

**6-4 Layer 2 하수 역류 위험 (G006 → G008)**:
- *민원 LLM 구조화* (`src/agent/classify_complaint.py`): PII 정규식 마스킹(원문 `data/raw/private/` .gitignore) → JSON 강제 프롬프트 `{location_text, address, dong, type∈[역류,침수,악취,막힘,파손,기타], rain_related, urgency 1~3, precision, confidence}` + few-shot 5건, temperature 0, 20건/배치, sha1 캐시 → V-World→카카오 지오코딩 → precision '동' 이하는 격자 라벨 제외. 검증: 층화 100건 2인 독립 라벨 → 유형 정확도 ≥85%, Cohen's κ ≥0.7(Gilardi et al., 2023의 표본 대조 원칙). 외부 API 전송 전 마스킹 검수 100건 샘플 확인(R11).
- *라벨·검증 세트의 출처별 분리(순환 방지)*: **L2 라벨 = E12(하수도사업소 민원) 중 역류·막힘·(하수 기인) 침수형, 악취 제외** / **L1 검증 = A6 시민의소리·A2 침수흔적의 침수형(E12 침수형과 중복 건은 L1 검증에서 제외)**.
- *Plan A* (관로별 좌표·연도 회신 시): 격자 단위, **유니버스 = 하수처리구역 내 & 관로 존재 격자**, 라벨=3년 역류·막힘·하수 기인 침수형 민원 ≥1, 피처=관로 평균·최대 경과연수, 30년↑ 연장비, 관경, 흄관 비율, 관로밀도(km/㎢), 합류식 존재 플래그, 상대고도, TWI, 불투수율, 하천거리, 예상 침수심, 펌프장 서비스권, 시간최대강우, 인구밀도(신고 노출 통제). XGBoost(max_depth 3~5, lr 0.05, 500+early stopping, scale_pos_weight), **행정동 GroupKFold 5-fold 공간 CV**, 베이스라인 로지스틱, SHAP TreeExplainer(mean|SHAP| Top5). L2 = out-of-fold 확률(Fontecha et al., 2021의 1단계만 단순 적용).
- *Plan B* (회신 무관 즉시 착수): `L2 = [(mm(노후율)+ε)(mm(관로밀도)+ε)(mm(민원밀도_동)+ε)]^(1/3)`, ε=0.05, 가법형 병기. **노후율 = A9 2-3 읍면동×매설연도(784행)의 30년↑ 매설연장 비율, 또는 Weibull P_defect(age)=1−exp[−(age/η)^β]의 경과연수 가중평균(η·β는 강병준 외 2020 범위: 중대결함 50% 초과 11~16년·90% 27~30년)**. 합류식은 총연장의 0.2%(7,136m)라 변수에서 제외하고 **'합류식 존재 플래그(보조)'**로 격하(G002에서 읍면동별 0 비율 확인 후 확정). 민원밀도는 동별 건수/㎢를 격자에 인구 비례 배분. 검증용 '민원 제외 점수' = 노후율×관로밀도.
- Decision Gate(G006, 9/3)는 "A를 추가하느냐"만 결정한다(§8-3 게이트 규칙).
- 동일 문구를 ANALYSIS_PLAN §3-1·§3-2·§7·§8(G008 행)에 동기화한다.

**6-5 Layer 3 취약계층 (G009)**: 65세↑ 비율(SGIS 집계구 → 100m 인구비례 배분, 균등 배분 대안 민감도; V는 비율·E는 수로 이중계산 방지, 소수 격자 베이즈 축소 `(x+20p̄)/(n+20)`), 1인가구 비율(SGIS OpenAPI 집계구 1인가구 확보 시 동일 배분; 미확보 시 제외 플래그 + B2 jumin 읍면동 1인세대로 대조만), 노후건물 비율(30년↑)·지하층 건물 수(GIS건물통합정보 SHP 1순위, 건축HUB 보완), 지상 임시주거시설 접근성 — **연속지표 `min(d,2km)/2km` + 고령자 보행 5분 300m 이진 보조지표 병기**(박재국·김동문, 2012)(펌프장은 L1에만). z-score 합산 → L3=minmax, Jenks 4등급, |r|>0.8 쌍은 하나만 채택(Balica et al., 2012), VIF<5.

**6-6 통합 CDRI·가중치·5등급 위험 분류 체계 R1~R5 (G010)** — 상세는 **`docs/CDRI_GRADE_SYSTEM.md`**(v2, 2026-08-19), 채택은 `docs/decisions/003-grade-system.md`
- **점수**: H = 0.5·L1 + 0.5·L2(처리구역 밖 H=L1 플래그), E = minmax(z인구밀도+z건물수), V = L3. **가중기하평균 CDRI = H^wH·E^wE·V^wV**(기본 1/3; H·V는 [0.05,1] 재척도, E=0 제외; 승법 근거 IPCC AR5·OECD/JRC 비보상성·Choi 2019), 가법형 ΣwX 병기(Moreira et al. 2021의 기하평균 과소평가 지적). 가중치 3안: 동일(Balica 'without weighting') / 엔트로피(이선미 외, 2020) / AHP 3×3(팀 3인+하수도사업소 1인, CR<0.1, RI=0.58, 9/8 마감; Saaty 1990; **9/8 미회수 시 팀 3인 AHP만 사용 + 응답자 수 한계 명시**). 가중치·정규화·집계 가정을 흔드는 민감도 절차는 Saisana et al.(2005)을 따른다. 500m MAUP 재집계.
- **등급(요약)**: 유니버스 minmax 0~1 → **R1~R5 오름차순(5=최위험)**, 명칭은 행동어 — R5 최우선 대응 / R4 우선 대응 / R3 점검 강화 / R2 일반 관리 / R1 관찰(색 ColorBrewer YlOrRd). 위기경보 상황명(관심·주의·경계·심각), 로마숫자(L1 내부 I~IV만), 개선지구 가나다라, 법정 지정명(하수도정비중점관리지역)과 겹치지 않게 하고, "분석용 상대 등급, 법정 지정과 무관" 각주를 고정한다. 등급 부여 3안: **1안 Balica 고정경계**(<0.01/0.01–0.25/0.25–0.50/0.50–0.75/0.75–1; 출처 Balica(2012) UNESCO-IHE 학위논문, Karmaoui et al.(2016) Table 4 재수록, 국제 비교용) / **2안 Jenks 5급** / **3안 캘리브레이션**(목표 비율 2/8/20/30/40% — 설계 선택, 침수흔적 사상 2020~21 캘리브레이션·2022~23 검증의 시간 분할, PAV 단조 발생률 곡선, 격자 부트스트랩 500회 CI, 내수 사상만으로 단조성 1회). **본안 분기(사전 고정)**: 유니버스 내 침수흔적 양성 격자 ≥100이고 사상이 2개 이상 기간이면 3안 본안·1안·2안 병기, 아니면 **2안 Jenks 본안**(또는 고정 백분위), 3안은 민감도로 강등; 세 안을 같은 격자에 병기해 가중 κ 보고.
- **결정 규칙(3개, A·B 합산 상향 ≤2단계, 변경 격자 ≤유니버스 5%)**: A 하한 보장(L1 백분위 ≥99, Plan A 시 L2 ≥99 포함 → 한 단계 상향, 결과 R3 미만이면 R3) / B 취약계층 상향(V 상위 10% 그리고 H 상위 30% → 한 단계 상향, 인명 우선의 의도적 정책 규칙; 서정석·한우석 2019, 박재국·김동문 2012; 20%/40% 대안 민감도) / C 기지정 재검토 태그(개선지구·내수 위험지구 13·침수취약 58 200m 내 격자 등급 불변, R1·R2면 '재검토' 플래그 — 강제 상향 시 §6-7 대조가 순환되므로 금지). `grade_raw`(검증용)·`grade_final`(대응표용) 모두 저장, 규칙별 변경 격자 수를 표 각주에 보고. **TOP 20은 CDRI 점수 순(300m NMS 후)으로 선정하며 규칙의 영향을 받지 않는다**(표에 grade_raw·grade_final·주 원인 병기, 원 표는 부록).
- **대응 행동표**: 열 = 평시 / 비상1단계(호우주의보) / 비상2단계↑(호우경보·극한호우); 환경부 하수관로 매뉴얼이 예시로 제시한 3단 유지관리 구분(모니터링→개선→보수)을 차용하되 **연간 물량(CCTV 조사·준설·부분보수)의 배분 우선순위**로 쓴다(상세·출처는 CDRI_GRADE_SYSTEM §0·§3). 기여도 = 가법 구성비 `w_kX_k/Σw_jX_j`(%), 최대 백분위 요소 = "주 원인".

**6-8 AI 요소의 자리 (decision 002)**

**포지셔닝 원칙 (2026.08.18 결정)**: 이 대회는 **데이터 분석 공모전**이다(제출물=분석보고서, 심사=창의성·정책 실현성·데이터 분석 적정성). AI는 **분석 안에서 필요한 자리에만** 쓴다 — ① 민원 텍스트 LLM 구조화(Layer 2 입력), ② XGBoost/SHAP 역류 예측. 알림 Agent는 활용방안 챕터의 **출력부 예시 1개(≤1p)**, 시민 챗봇은 **삭제**. 보고서 비중 = 분석 75 / 활용·Agent 15 / 개요·출처 10.

### 8-1 하네스 구조와 원칙

이 계획은 "할 일 목록"이 아니라 **증거 게이트로 연결된 스토리 체인**입니다.

```
Story N  ──[증거 제출]──▶  checkpoint  ──▶  Story N+1 활성화
              │
              └─ 증거 없으면 완료 불가 (goals.py가 거부)
```

| 원칙 | 구현 |
|---|---|
| 각 스토리 = 목표 + 입력 + 산출물 + **검증 기준** | 이 문서 §8-3 |
| 다음 스토리는 이전 스토리 checkpoint 후에만 시작 | `goals.py next` |
| 완료 주장에는 반드시 증거(파일 경로·수치·로그) | `goals.py checkpoint --evidence` |
| 결정은 기록으로 남김 | `docs/decisions/NNN-*.md` |
| 분기점(Decision Gate)은 증거 기반으로 Plan A/B 선택 | G006 |
| 최종 스토리는 검증 명령 없이 완료 불가 | `--verify-cmd` 게이트 |
| 상태는 파일로 영속화 → 세션·사람이 바뀌어도 이어감 | `.fablize/goals.json` + git |

**하네스 운영 명령** (진행 상태는 `.fablize/goals.json`에 영속화)

```bash
# 저장소 루트에서
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py status      # 현재 상태
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py next        # 다음 스토리 활성화 + 핸드오프 출력
python3 /mnt/c/Users/User/.claude/plugins/fablize/scripts/goals.py checkpoint --id G00N --status complete --evidence "..."
```

**G007 Layer 1 침수 취약성** — R1 · 9/8

**G008 Layer 2 역류 위험** — R2 · 9/12(Plan A 추가 시 9/14)

- 공통: `classify_complaint` LLM 배치(PII 마스킹·검수 100건, JSON 스키마, 캐시) → V-World→카카오 지오코딩 → 격자 라벨 (`complaints_labeled.csv`); **시민의소리 스크래핑분으로 회신 전 선착수**; 출처별 분리 — L2 라벨=E12 역류·막힘·하수 기인 침수형(악취 제외) / L1 검증=A6·A2 침수형(E12 중복 제외)
- Plan A: 유니버스=처리구역 내 & 관로 존재 격자; 격자 피처(경과연수·30년↑비율·관경·흄관비율·**관로밀도**·합류식 플래그·상대고도·TWI·불투수·하천거리·예상침수심·펌프장·시간최대강우·인구밀도) → XGBoost, `scale_pos_weight`, **행정동 GroupKFold 5-fold 공간 CV** → out-of-fold 확률 = L2, SHAP Top5
- Plan B: `[(노후율+ε)(관로밀도+ε)(민원밀도+ε)]^(1/3)` (노후율=A9 읍면동×매설연도 30년↑ 비율 또는 Weibull P_defect; 합류식은 플래그) → minmax; 가법형 병기

- **검증**: LLM 유형 정확도 ≥85%·κ ≥0.7(2인 100건) + A → 공간CV PR-AUC ≥ 양성비×2, ROC-AUC ≥0.70, mean|SHAP| Top5에 노후 변수 ≥1 / B → **민원 제외 점수(노후율×관로밀도)** vs 동별 민원 순위 ρ ≥0.4 / 공통 → 저감종합계획 내수 위험지구 13개소 격자 L2 백분위 중앙값 ≥70

**G010 통합 위험지수 CDRI + R1~R5 등급 + TOP 20** — R1+R2 · 9/15
