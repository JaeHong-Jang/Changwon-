## 1부. 재검증 결과 — 앞서 보고한 숫자 중 무엇이 살아남았나

"포착률 0.000 과 1.000 이 같은 표에 나오는 게 이상하다", "정확도 편차가 너무 크다"는
지적을 받고 표본 구조부터 다시 봤다. **근본 원인이 둘 나왔고, 앞서 보고한 결론 여러 개가
무너졌다.** 승인 판단에 직접 영향을 주므로 여기부터 읽는다.

### 1-1. 근본 원인 A — 격자 수는 표본 수가 아니다 (유사복제)

침수흔적 폴리곤 하나가 격자 수십 칸을 덮는다. **붙어 있는 격자는 같은 침수 한 건**이다.
그런데 AUC·p 값·신뢰구간은 격자가 독립이라고 가정하고 계산했다.

| | 격자 | 독립 침수(덩어리) |
|---|---:|---:|
| 전체 양성 | 642 | **46** |
| 2006 에위니아 | 107 | **3** |
| 2019 미탁 | 56 | **3** |
| 등급 검증 기간 양성 | 180 | **12** |
| 그중 R5 | 9 | **1** |

**0.000 과 1.000 이 나온 이유가 이것이다.** 2006 년 "107칸"은 사실상 3곳이다. 3곳이 전부
점수가 낮으면 포착률은 정확히 0 이 되고, 2019 년 3곳이 전부 시가지면 불투수면 > 0 비율은
정확히 1 이 된다. 극단값은 표본이 작다는 신호였다.

**편차가 큰 이유도 이것이다.** 사상당 유효 표본이 3~14 곳이라 AUC 는 "그 몇 곳이 마침
높은 점수였나"에 좌우된다. **시 침수예상도 단독으로 채점해도 사상별 표준편차가 0.237** 로
우리 지수(0.261)와 거의 같다 — 어떤 지수를 써도 이 표본에서는 이만큼 흔들린다.

격자 단위로 재표본하면 신뢰구간이 **6.5배 좁게** 나온다(폭 0.035 vs 0.226).
좁은 쪽을 보고하면 확신을 과장하게 된다.

### 1-2. 근본 원인 B — 성능의 상당 부분이 시 침수예상도에서 온다 (순환)

시 침수예상도는 Layer 1 의 **입력**이다. 흔적이 예상도 안에 있으면 우리 지수는
"이미 아는 곳"을 맞히는 셈이다. 사상별 AUC 가 예상도 겹침으로 거의 그대로 설명된다.

| 연도 | 흔적이 예상도와 겹친 면적 | AUC |
|---|---:|---:|
| 2006 | **0.000** | 0.389 |
| 2025 | **0.000** | 0.367 |
| 2014 | 0.192 | 0.786 |
| 2012 | 0.387 | 0.792 |
| 2019 | **0.831** | 0.962 |
| 2016 | **0.845** | 0.920 |

그래서 예상도 단독 점수와 나란히 놓았다.

| 지수 | AUC | 덩어리 단위 95% 구간 |
|---|---:|---|
| **시 침수예상도 단독** | **0.709** | [0.589, 0.826] |
| Layer 1 현행 | **0.750** | [0.637, 0.863] |
| Layer 1 − 예상도 | 0.734 | [0.621, 0.837] |

**시가 이미 가진 예상도만으로 0.709 가 나온다. 우리 증분은 +0.041 이고, 구간이 겹쳐
통계적으로 구분되지 않는다.** 예상도를 빼도 0.734 가 남으니 우리가 베끼기만 한 것은
아니지만, "AUC 0.750 을 달성했다"고만 쓰면 시 모형의 성과를 우리 것으로 보고하게 된다.

### 1-3. 무엇이 살아남고 무엇이 무너졌나

| 앞서 보고한 것 | 지금 판정 | 이유 |
|---|:--:|---|
| Layer 1 AUC 0.750, 게이트 통과 | **점추정만 유효** | 95% 구간 [0.637, 0.863] 이 기준 0.70 을 포함 |
| 상위 20% 포착률 54.4% | 점추정만 유효 | 같은 이유 |
| 우리 지수가 실제 침수를 잘 맞힌다 | **수정** | 시 예상도 단독 0.709, 증분 +0.041, 구분 불가 |
| 사상별 편차는 농경지 때문 | **철회** | 표본 구조 탓. 시 예상도도 같은 편차 |
| 2006·2025 는 예상도·펌프권 밖이라 실패 | 유지 | 시 예상도도 두 사상에서 0.440 (무작위 이하) |
| 2014 는 하천 근접이 잡았다 | 유지 | 예상도 0.581 → 우리 0.786 (+0.205), 하천 200m 내 75.8% |
| 등급이 오를수록 더 잠긴다 (p = 4.9×10⁻⁸) | **철회** | 검증 침수 12건, 단조 재표본 35.9% |
| R5 는 기저의 7.3배 | **철회** | R5 양성 = 침수 1건, lift 구간 [0.00, 22.62] |
| 자료가 3단 구조를 뒷받침한다 | **철회** | 3단도 같은 12건에 기댄다 |
| 등급 경계가 파라미터에 안정적이다 | 유지 | ±2·±3%p 에서 동일 (표본과 무관한 성질) |
| hindcast 원안 불가 | 유지 | 과거 시점 지형·피복 자료 없음 |

### 1-4. 그래서 보고서에 쓸 수 있는 문장

**쓸 수 있다**
- "시 침수예상도(AUC 0.709)에 지형·인구·취약성·대응역량을 결합해 우선순위를 만들었고,
  실제 침수흔적 대조에서 AUC 0.750 이었다. 다만 독립 침수가 46건이라 95% 구간이
  [0.64, 0.86] 으로 넓고 예상도와의 차이는 통계적으로 확정되지 않는다."
- "시 예상도가 놓친 하천변 침수(2014)에서는 우리 지수가 크게 나았다(0.58 → 0.79)."
- "시 예상도와 펌프 서비스권 밖에서 일어난 침수(2006·2025)는 시 모형과 우리 지수 모두
  짚지 못했다."
- "R1~R5 는 발생률 캘리브레이션 절차로 정한 재현 가능한 행정 우선순위 구간이다."

**쓸 수 없다**
- "AUC 0.750 으로 검증 기준을 통과했다" (구간을 빼고)
- "등급이 오를수록 실제로 더 잠긴다"
- "R5 는 기저보다 7배 위험하다"
- "우리 지수가 시 예상도보다 낫다"

### 1-5. 기여를 어디에 둘 것인가

성능 숫자로는 시 예상도와 구분되지 않는다. 그러면 이 프로젝트의 기여는 무엇인가.

**예상도는 "어디가 잠기는가"만 말한다.** 예상도로는 TOP 20 을 뽑을 수 없다 — 사람이
안 사는 논밭과 고령자 밀집 주거지가 같은 침수심이면 같은 점수다. CDRI 는 거기에
**누가 사는가(E)·얼마나 취약한가(V)·대응역량이 있는가(D)** 를 결합해 **행정이 먼저
움직일 곳의 순서**를 만든다. 기여는 예측 정확도가 아니라 **의사결정 단위를 바꾸는 것**이다.

이 방향으로 보고서의 주장을 옮기면, 검증 결과는 약점이 아니라 **"시 모형의 정확도를
해치지 않으면서 우선순위를 더했다"** 는 근거가 된다 (0.709 → 0.750, 최소한 나빠지지 않음).

> 코드 `src/data/uncertainty.py`, `h06_layers._incremental_value`, `h07_cdri._reporting_constraint`

### 2-2. R3 승인 3건 — 분석 결과를 확정할 것인가

#### ⑨ `h07_cdri` — primary 산식·가중치 확정 (승인 후 재조정 금지)

**확정되는 것.**

$$\text{CDRI} = \prod_k X_k^{\,w_k}, \quad X \in \{H, E, V, D\},\ w_k = 0.25,\ X_k \in [0.05, 1]$$

- 집계: 가중기하평균 (근거: IPCC AR5 세 요소 필요조건, OECD/JRC 2008 비보상성)
- 가중치: 동일가중 (AHP 전문가 설문 미수집으로 3안 제외, 엔트로피는 비교용)
- 순위 대상: 인구 > 0 또는 주택 ≥ 1인 격자 **10,202칸**
- Layer 2 **제외** (관로 비공개, `decisions/001`)
- 등급 본안: **캘리브레이션** (`decisions/003`의 3안)

**같이 확정되는 제약 — 이게 중요하다.**

강건성 게이트가 **미달**이다. TOP 20 최소 중첩이 9/20으로 기준 14에 못 미친다.
임계를 낮추는 재튜닝은 금지이므로 `ranking_mode = "tier"`로 전환됐다.
즉 **정밀 순위를 주장하지 않고** 위험군과 "어떤 산식으로도 상위에 드는 8칸"으로 보고한다.

여기에 1부의 재검증 결과가 더해진다 — AUC 구간이 기준을 포함하고, 시 예상도와 구분되지 않으며, 등급 간 위험 차이는 검증되지 않았다. **이 모두를 받아들이고 산식을 동결하는 승인**이다.

| 확인할 것 | 값 |
|---|---|
| 중위 Spearman ρ | 0.878 (최소 0.848, 기준 0.80 통과) |
| TOP 20 최소 중첩 | **9 / 20** (기준 14 **미달** → tier 모드) |
| 강건 공통집합 | 8칸 |
| 구성요소 결측 0 대체 | 없음 (있으면 중단하게 돼 있음) |

①~⑧은 바로 승인해도 무방하다고 본다. **⑨·⑩·⑪은 위 그림 2장과 `top20.csv`를 직접 보고
결정하시길 권한다** — ⑨는 승인 후 산식 재조정이 금지되고, ⑪은 사람 눈 확인이 조건이다.

**⑨에 대한 판단 재료가 크게 바뀌었다.** 앞서는 "R5 70칸만 분리 가능"을 수용하느냐의
문제였는데, 지금은 **"등급 간 위험 차이를 전혀 주장하지 않고, 성능도 시 예상도와
구분되지 않는다"** 를 수용하느냐의 문제다.

두 가지 길이 있다.

1. **승인** — 기여를 예측 성능이 아니라 우선순위 산출에 둔다(1-5). 산식은 동결되고
   보고서는 1-4 의 "쓸 수 있는 문장"만 쓴다. 9/30 마감 안에 가능하다.
2. **거부** — 검증 표본을 늘리거나 예상도와 독립적인 변수를 보강해 증분을 키운다.
   다만 **마감 전에 검증 침수를 늘릴 경로가 없다**(행안부 API 는 2018 년까지, 시 회신은
   2025 년 1건, 민원은 비공개). 변수를 보강해도 같은 46건으로 재검증하게 되어
   이번에 찾은 문제가 그대로 남는다.

현실적으로는 1번을 권한다. 다만 **이것은 분석 결과의 성격을 바꾸는 결정**이므로
직접 판단하시기 바란다.
