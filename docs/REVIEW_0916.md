## 1부. 재검증과 수정 — 무엇이 고쳐졌고 무엇이 남았나

"포착률 0.000 과 1.000 이 같은 표에 있는 게 이상하다, 정확도 편차가 너무 크다"는 지적을 받고
표본 구조를 다시 봤다. 근본 원인이 둘 나왔고, 둘 다 **평가 방법을 고쳐** 다시 쟀다.

### 1-1. 원인 A — 격자 수는 표본 수가 아니다 (유사복제)

침수흔적 폴리곤 하나가 격자 수십 칸을 덮는다. **붙어 있는 격자는 같은 침수 한 건**이다.

| | 격자 | 독립 침수 |
|---|---:|---:|
| 전체 양성 | 642 | **46** |
| 2006 에위니아 | 107 | **3** |
| 2019 미탁 | 56 | **3** |

**0.000·1.000 이 나온 이유**: 2006년 "107칸"은 사실상 3곳이다. 3곳이 전부 점수가 낮으면 포착률은
정확히 0, 2019년 3곳이 전부 시가지면 불투수면 비율은 정확히 1 이 된다.
**편차가 큰 이유**: 사상당 독립 침수가 3~14 건이라 AUC 가 크게 흔들린다. 시 예상도로 채점해도
사상별 표준편차가 0.237 로 우리(0.261)와 같다.

**수정 ① — 침수 1건 = 1표로 센다.** 재표본은 덩어리 단위로 하고, AUC 도 침수마다 1표로 센다.

| | AUC | 95% 구간 |
|---|---:|---|
| 격자마다 1표 | 0.750 | [0.633, 0.863] |
| **침수마다 1표** | **0.704** | [0.629, 0.775] |

게이트(격자 가중 ≥ 0.70)는 통과했지만 **구간이 기준을 포함하므로 "확실히 넘었다"고는 쓰지 않는다.**

**수정 ② — 등급 검증을 사상 단위 교차검증(LOEO)으로 바꾼다.** 앞 3개/뒤 3개 시간 분할은 검증
침수가 12건(R5 는 1건)뿐이었다. 설계 문서가 미리 정한 대안대로 사상을 하나씩 빼고 나머지로
경계를 맞춰 채점하니 검증 침수가 **46건**으로 늘었다. → 결과는 1-3.

### 1-2. 원인 B — 시 침수예상도에서 온 성과가 섞여 있다 (순환)

시 침수예상도는 Layer 1 의 **입력**이다. 사상별 AUC 가 "흔적이 예상도와 얼마나 겹치나"로 거의
그대로 설명됐다(겹침 0 → AUC 0.37~0.39, 겹침 0.83~0.85 → 0.92~0.96).

**수정 — 짝지어 비교하고, 예상도가 정보를 주지 않는 구역에서 따로 잰다.**

앞서 "두 신뢰구간이 겹치니 구분되지 않는다"고 썼는데 **틀린 검정이었다.** 같은 침수들로 채점한
두 점수는 상관돼 있어서 차이를 직접 재야 한다.

| 비교 (기준: 시 예상도) | 차이 | 95% 구간 | 나을 확률 |
|---|---:|---|---:|
| Layer 1, 격자 1표 | +0.041 | [−0.003, +0.099] | 96.4% |
| **Layer 1, 침수 1표** | **+0.081** | **[+0.024, +0.139]** | **99.9%** |
| 예상도 변수를 뺀 Layer 1, 침수 1표 | +0.073 | [+0.013, +0.135] | 99.4% |

| 구역 | 시 예상도 | Layer 1 |
|---|---:|---:|
| **예상도 밖** (창원 격자의 88%, 침수 37건) | 0.500 (정보 없음) | **0.634** |
| 예상도 안 (침수 20건) | **0.652** | 0.588 |

**침수마다 1표로 세면 우리 지수는 시 예상도보다 확실히 낫다.** 예상도가 없는 곳에서 정보를
더하고(0.634), 예상도가 있는 곳에서는 그 신호를 조금 흐린다(0.588 < 0.652).
격자 1표로 경계선인 이유는 예상도 안쪽의 큰 시가지 침수 몇 건이 격자 수로 점수를 끌어올리기 때문이다.

예상도 안에서 신호를 흐리는 문제는 개선 여지로 기록한다. **검증 결과를 보고 가중치를 고치면
재튜닝이므로 지금 산식에는 반영하지 않았다.**

### 1-3. 등급 — 경계는 안정적이고, 등급 간 위험 차이는 여전히 검증되지 않았다

사상 단위 교차검증 결과:

| 등급 | 발생률 | lift | 독립 침수 |
|---|---:|---:|---:|
| R1 | 0.47% | 0.84 | 35 |
| R2 | 0.54% | 0.97 | 23 |
| R3 | 0.52% | 0.94 | 16 |
| R4 | 0.77% | 1.38 | 8 |
| R5 | 4.39% | 7.85 | **3** |

- **경계는 어느 사상을 빼도 거의 같다** — 폴드 간 폭 최대 0.016, 가운데 두 경계는 0
- 등급이 오를수록 더 잠길 확률 **91.9%** — 사전 기준 99% 미달
- **R1·R2·R3 은 사실상 같다** — 표본 문제만이 아니라 실제로 갈리지 않는다
- R5 lift 구간 [0.00, 16.85] — R5 는 독립 침수 3건

**표본을 12→46건으로 늘려도 결론이 바뀌지 않았다.** 이것도 정직한 결과다.

### 1-5. 보고서에 쓸 수 있는 문장

**쓸 수 있다**

  46건 대조에서 0.70 이었고, 예상도보다 +0.08(95% 구간 +0.02~+0.14) 높았다."

- "우리 지수는 모든 곳에서 시 예상도보다 낫다"

### 2-2. R3 승인 3건 — 분석 결과를 확정할 것인가

#### ⑨ `h07_cdri` — primary 산식·가중치 확정 (승인 후 재조정 금지)

**확정되는 것.**

$$\text{CDRI} = \prod_k X_k^{\,w_k}, \quad X \in \{H, E, V, D\},\ w_k = 0.25,\ X_k \in [0.05, 1]$$

- 집계: 가중기하평균 (근거: IPCC AR5 세 요소 필요조건, OECD/JRC 2008 비보상성)
- 가중치: 동일가중 (AHP 전문가 설문 미수집으로 3안 제외, 엔트로피는 비교용)
- 순위 대상: 인구 > 0 또는 주택 ≥ 1인 격자 **10,202칸**
- Layer 2 **제외** (관로 비공개, `decisions/001`)
- 등급 본안: **캘리브레이션** (`decisions/003`의 3안)

**같이 확정되는 제약 — 이게 중요하다.**

강건성 게이트가 **미달**이다. TOP 20 최소 중첩이 9/20으로 기준 14에 못 미친다.
임계를 낮추는 재튜닝은 금지이므로 `ranking_mode = "tier"`로 전환됐다.
즉 **정밀 순위를 주장하지 않고** 위험군과 "어떤 산식으로도 상위에 드는 8칸"으로 보고한다.

여기에 1부의 결과가 더해진다 — AUC 구간이 기준을 포함하고, 예상도 안쪽에서는 예상도보다 낮으며, 등급 간 위험 차이는 검증되지 않았다. 반대로 침수 1표 기준으로 예상도보다 확실히 낫고 경계는 안정적이다. **이 전체를 받아들이고 산식을 동결하는 승인**이다.

| 확인할 것 | 값 |

| 중위 Spearman ρ | 0.878 (최소 0.848, 기준 0.80 통과) |

**⑨에 대한 판단 재료.** 수정된 평가로 보면 이 승인은 다음을 동결한다.

- 지수는 **침수 1건 = 1표 기준으로 시 예상도보다 확실히 낫다**(+0.081). 이것이 보고서의 주 근거다.
- 다만 **예상도 구역 안에서는 예상도 단독보다 낮다**. 가중치를 고치면 나아질 여지가 있지만,
  승인 후에는 재조정이 금지된다. 고치려면 **승인 전에** 결정해야 하고, 그 경우에도 이번 46건으로
  다시 채점하게 되어 "검증 자료를 보고 고친 산식"이라는 약점이 남는다.
- 등급은 **안정적인 우선순위 구간**으로만 주장한다.

권고는 **승인**이다. 예상도 안쪽의 약점은 한계와 차기 과제로 쓰는 편이, 검증 자료를 본 뒤
산식을 고치는 것보다 방어하기 쉽다. 다만 분석 결과의 성격을 정하는 결정이므로 직접 판단하시기 바란다.
