## ① 민원 부분공개 이의신청 — **이번 주 안에** (최우선)

### 왜 하는가

2026-09-01 회신에서 창원시가 민원 3년치를 비공개했다. 사유는 두 가지였다.

> 해당 공문에는 민원인의 성명, 연락처, 주소 등 개인에 관한 정보가 포함되어 있어
> 「공공기관의 정보공개에 관한 법률」 제9조제1항제6호에 따른 비공개 대상정보에 해당하는
> 부분이 포함되어 있습니다. 청구하신 자료는 공문서로 등록 관리되고 있어 **원문수정이 불가**하며…

이 논리에는 반박할 근거가 있다. 같은 법 **제14조(부분공개)** 는 이렇게 정한다.

> 공개 청구한 정보가 제9조제1항 각 호의 어느 하나에 해당하는 부분과 공개 가능한 부분이
> 혼합되어 있는 경우로서 공개청구의 취지에 어긋나지 아니하는 범위에서 두 부분을 분리할 수
> 있는 때에는 제9조제1항 각 호의 어느 하나에 해당하는 부분을 **제외하고 공개하여야 한다.**

즉 개인정보가 섞여 있다는 것은 **전부 비공개의 사유가 되지 못한다.** 분리할 수 있으면
나머지를 공개할 의무가 있다. "원문수정 불가"도 답이 되지 않는다. 부분공개는 원문을 고치는 것이
아니라 개인정보 부분을 가린 사본을 주는 것이다.

### 기한

| 항목 | 근거 | 날짜 |
|---|---|---|
| 이의신청 기한 | 법 제18조① 통지받은 날부터 **30일** | 결정통지 열람 9/1 → **10/1까지** |
| 기관의 결정 기한 | 법 제18조③ 신청받은 날부터 **7일** (+7일 연장 가능) | |

**보고서 마감이 9/30이므로 10/1까지 기다릴 수 없다.** 9/8~9/10에 내야 9/15~9/22에 결과가 나와
보고서에 반영할 수 있다. 늦어도 이번 주 안에 제출한다.

### 방법

정부24(https://www.gov.kr) → 정보공개 → **이의신청**. 기존 접수번호 **17369500** 을 지정한다.
대상 기관은 원 결정을 한 부서(창원시 하수도사업소 등 민원 항목 처리부서)다.

### 제목

```
정보공개 비공개결정(접수번호 17369500)에 대한 이의신청 — 부분공개 요청
```

### 본문 (그대로 복사해서 붙여넣기)

```
1. 이의신청의 대상
   - 원 청구 접수번호: 17369500
   - 결정통지일: 2026년 9월 1일
   - 대상 항목: "침수 및 하수도 관련 민원" 비공개 결정
   - 원 결정 사유: 「공공기관의 정보공개에 관한 법률」 제9조제1항제6호(개인정보) 및
     "공문서로 등록 관리되어 원문수정 불가"

2. 이의신청의 취지
   위 결정 중 개인정보에 해당하지 않는 부분에 대하여 부분공개를 요청합니다.

3. 이의신청의 이유

   가. 같은 법 제14조는 비공개 대상 부분과 공개 가능한 부분이 혼합된 경우,
       두 부분을 분리할 수 있는 때에는 비공개 부분을 제외하고 공개하여야 한다고
       정하고 있습니다. 개인정보가 포함되어 있다는 사정만으로 자료 전부를 비공개하는 것은
       위 조항의 취지에 부합하지 않는다고 사료됩니다.

   나. "원문수정이 불가하다"는 사유와 관련하여, 본 청구인이 요청하는 것은 원문의 수정이
       아니라 개인 식별정보를 제외한 형태의 제공입니다. 원 청구서에서도
       "민원인 성명, 연락처 등 개인정보는 제외 요청"이라고 명시한 바 있습니다.

4. 요청 사항
   아래 두 형태 중 귀 기관이 처리하기 용이한 어느 하나로 제공하여 주시기 바랍니다.

   [형태 A] 개인 식별정보를 가린 사본
     - 민원인 성명·연락처·상세주소(번지 이하)를 마스킹한 근무일지 사본

   [형태 B] 항목만 추출한 목록
     - 접수일자 (연월일까지, 시각 불요)
     - 민원 유형 (침수 / 하수 역류 / 맨홀 넘침 / 배수 불량 / 기타)
     - 발생 위치: **행정동 단위까지만** (번지·상세주소 불요)
     - 처리 결과 (처리완료 / 진행중 등)

   ※ 형태 B의 위치 정보를 행정동 단위로 한정한 것은, 개인 식별 가능성을
      최소화하기 위함입니다. 연구 목적상 행정동 단위 집계로도 분석이 가능합니다.

5. 이용 목적
   2026년 창원시 AI·데이터 활용 공모전 출품을 위한 학술 분석입니다.
   개인을 식별하거나 특정하려는 목적이 전혀 없으며, 분석 결과는 행정동 단위 이상으로만
   공표합니다. 원자료는 외부에 재배포하지 않습니다.

6. 기간
   2023년 1월 1일 ~ 현재 보유 최신일자

감사합니다.
```

## ② 홍수위험지도 SHP — 30분 (쉬움)

### 왜 하는가

우리가 뽑은 우선대응 20곳이 **국가가 만든 공식 침수 시나리오와 겹치는지** 대조하려는 것이다.
지금은 창원시 자체 침수예상도만 쓰고 있어서, 서로 다른 기관의 자료로 교차 확인이 안 된다.

### 받을 것

https://data.floodmap.go.kr/main/board/map_data_download
(로그인·인증키 필요 없다. 바로 zip 다운로드)

창원시 5개 구의 구코드는 **48121 의창 / 48123 성산 / 48125 마산합포 / 48127 마산회원 / 48129 진해** 다.

| 종류 | 파일명 형태 | 개수 |
|---|---|---|
| **도시침수지도 100년** | `CFM_SGG_4812x_100.zip` | 5개 (구별) |
| **지방하천 범람 100년** | `RFM_SGG_RGN_4812x_100.zip` | 5개 (구별) |

100년 빈도만 받으면 된다. 다른 빈도(30·50·80·500년)는 여유 있으면.

### 저장 위치

```
data/raw/flood_maps/floodmap_go_kr/
```

zip 을 그대로 두지 말고 **압축을 풀어서** 넣는다 (`.shp .dbf .shx .prj` 가 한 세트).

### 주의

**공공누리 4유형**이다. 보고서에 인용하고 지도로 보여주는 것은 되지만,
이 자료를 가공한 파일을 외부에 배포하면 안 된다. 이 사실을 README 비고란에 적는다.

## ③ V-World 건물 자료 — 반나절 (오래 걸림)

### 왜 하는가

지금 Layer 3 의 "취약성"에 **65세 이상 비율 딱 하나**만 들어가 있다.
분석 설계서는 여기에 **지하층 보유 건물 수**와 **노후 건물 비율**도 넣기로 했는데
자료가 없어 빠져 있다. 이게 현재 분석의 가장 큰 구멍 중 하나다.

지하층은 특히 중요하다. 2022년 서울 반지하 참사가 보여주듯 침수 인명피해가
가장 크게 나는 곳이다.

### 절차

1. **V-World 회원가입** — https://www.vworld.kr (무료)
2. **인증키 발급** — 마이페이지 → 오픈API → 인증키 신청. 즉시 발급된다
3. **GIS건물통합정보 다운로드**
   - https://www.data.go.kr/data/15083092/fileData.do 에서 안내를 따라
     V-World 로그인 후 **시군구 단위**로 받는다
   - 창원 5개 구를 모두 받는다

### 저장 위치

```
data/raw/buildings/
```

### 받은 뒤 **반드시 확인할 것** (이게 핵심)

파일을 열어 아래 두 정보가 있는지 확인하고 **컬럼 이름을 알려준다.**

| 필요한 정보 | 흔한 컬럼명 | 없으면 |
|---|---|---|
| **지하층 수** | `UGRND_FLR_CO`, `지하층수` 등 | 건축HUB API(data.go.kr 15134735)로 보완해야 한다 |
| **사용승인일** | `USEAPR_DT`, `사용승인일자` 등 | 노후 건물 비율을 못 만든다 |

QGIS 나 엑셀로 `.dbf` 를 열면 컬럼이 보인다. 컬럼 목록을 그대로 캡처해서 공유하면 된다.

**지하층수 컬럼이 없을 가능성이 있다.** 그때는 건축HUB API 키를 추가로 신청해야 하므로
확인이 빠를수록 좋다.

### 인증키를 받으면 같이 알려줄 것

`.env` 파일에 넣어야 하므로 키 문자열을 공유한다.
**키는 절대 Git 에 커밋하지 않는다** (`.env` 는 이미 `.gitignore` 에 있다).

## ④ 자연재해저감종합계획 위험지구 (여유 있으면)

### 상황

창원시 제2차 자연재해저감종합계획(안)에 **내수재해 위험지구 13개소**가 지정돼 있다.
우리 TOP 20 과 겹치는지 보면 "시가 이미 지정한 곳을 우리도 잡았나"를 확인할 수 있다.

**지구 이름 13개는 이미 안다** — 명서, 내동천, 귀곡, 창원천, 안민, 신촌, 신포(척산),
오동, 봉암, 석전, 구암, 안골, 용원.

그래서 이름만으로도 행정동 수준 대조는 가능하다. PDF 가 필요한 이유는
**각 지구의 대표 지번**을 얻어 격자 단위로 대조하기 위해서다.

### 받을 것

https://council.changwon.go.kr/svc/cmt/CmtBillView.do?cmmtCd=305015&billSn=245555

이 페이지의 첨부파일(안건 PDF, 약 27쪽)을 받는다.
**이전에 확인한 직접 다운로드 링크(`flSn=28864`)는 404 였다.** 페이지에서 첨부 번호를
다시 확인해야 한다.

### 저장 위치

```
data/raw/reference/
```

### 확인할 것

PDF 안에서 **내수재해 위험지구 13개소의 표**를 찾아, 지구명과 대표 지번을 옮겨 적는다.
(예: 명서 → 의창구 명서동 178-8)

## 공통 규칙

### 파일을 받으면 반드시 기록한다

`data/raw/README.md` 의 표에 한 줄을 추가한다. 네 가지가 필요하다.

| 항목 | 예 |
|---|---|
| 경로 | `flood_maps/floodmap_go_kr/` |
| 출처 기관 | 기후에너지환경부 한강홍수통제소 |
| URL | https://data.floodmap.go.kr/main/board/map_data_download |
| 취득일 | 2026-09-10 |
| 비고 | 도시침수 100년 5개 구 + 지방하천 100년 5개 구. 공공누리 4유형 — 파생 배포 금지 |

이 기록이 없으면 재현성 검증에서 막힌다. 심사에서도 출처를 못 댄다.

### md5 구하는 법

윈도우 PowerShell 에서:

```powershell
Get-FileHash -Algorithm MD5 "경로\파일명"
```

### 커밋

받은 원본은 Git LFS 로 올라간다. 그냥 `git add` 하면 된다.

```bash
git add data/raw/... data/raw/README.md
git commit -m "data: 홍수위험지도 SHP 취득 (창원 5개 구, 100년 빈도)"
git push
```

**브랜치를 확인한다.** 지금 작업은 `feat/research-harness` 에서 이어진다.
다른 브랜치에서 작업했다면 먼저 `git pull` 로 최신을 받는다.

### 저장소 최신 상태 받기

```bash
git checkout feat/research-harness
git pull
git lfs pull
```
