# CDRI 설명 분석 (2026-09-17)

기존 CDRI를 H·E·V·D 네 요소의 Shapley 기여도로 분해했다. 산식·가중치·등급·선정 지역은
바꾸지 않았다. 새 예측모델을 학습한 결과가 아니라, 현재 점수가 어떻게 구성됐는지 보여주는 XAI다.

## 방법

양수 재척도된 네 요소를 사용한다. 배경은 순위 대상 10,202격자 전체다. 요소를 고정하거나
배경 행으로 치환하는 16개 조합을 모두 계산한다. 빠진 요소끼리는 같은 배경 행을 공유한다.

각 조합의 기하평균을 기존 CDRI의 최솟값·최댓값으로 정규화하고, 요소 추가 전후의 차이를
Shapley 가중치로 평균한다. 이는 배경 치환을 사용하는
[SHAP의 설명 정의](https://shap.readthedocs.io/en/latest/generated/shap.KernelExplainer.html)와
[가법적 기여도 분해](https://arxiv.org/abs/1705.07874)에 따른다. 패키지나 근사 학습은 추가하지 않았다.

`기준값 0.369166 + H 기여 + E 기여 + V 기여 + D 기여 = 해당 격자 CDRI`

양수는 배경 평균보다 점수를 올린 몫, 음수는 낮춘 몫이다. 단위는 CDRI 점수이며 백분율이 아니다.

## 결과

| 요소 | 전체 평균 절대 기여도 | 우선대응 20곳 평균 기여도 |
|---|---:|---:|
| H 침수위험 | 0.0469 | +0.0743 |
| E 인구·주택 노출 | 0.1357 | +0.3548 |
| V 취약성 | 0.0671 | +0.0599 |
| D 대응부족 | 0.0576 | +0.0724 |

E가 전체 점수 차이와 선정 지역의 높은 점수에 가장 크게 기여했다. 따라서 선정 지역은
물리적으로 잠길 가능성만으로 뽑힌 곳이 아니라, 인구·주택 노출을 함께 고려한 대응 우선지역으로
설명한다. 동일가중이어도 입력 분포와 기하평균의 상호작용 때문에 기여도가 같지는 않다.

기존 `primary_cause`는 최대 백분위 요소를 사용하는 정책 분류다. 새 `xai_main_positive`는
배경 대비 점수를 가장 많이 올린 요소다. 두 값의 정의가 달라 기존 정책카드를 자동으로 바꾸지 않는다.

## 해석 범위

- CDRI 산식의 설명이다. Layer 1 AUC 개선이나 실제 침수 원인의 증거로 사용하지 않는다.
- 요소 치환은 관측된 요소와 빠진 요소 사이의 상관을 보존하지 않는다. 실제로 드문 조합도 포함한다.
- 기여도는 배경 선택에 따라 달라진다. 여기서는 기존 순위 대상 전체를 사용했다.
- R1~R5는 우선순위 구간이며, 정밀 순위·등급별 침수 확률의 검증 한계는 그대로다.

## 재현과 검증

`notebooks/04_modeling.ipynb`를 처음부터 실행한다. 6절에서 아래 파일을 만든다.

- `reports/tables/cdri_xai.csv`: 전체 격자별 설명
- `reports/tables/top20_xai.csv`: 선정 지역별 설명
- `reports/tables/cdri_xai_summary.csv`: 전체·선정 지역 요약
- `reports/figures/xai/`: 요약 그림과 선정 지역 기여도 그림
- `artifacts/evaluation/cdri_xai.json`: 배경·산식·원본 해시·복원 오차

24개 요소 추가 순서의 직접 치환 계산과 단위 테스트로 대조했다. 실제 10,202격자의
최대 점수 복원 오차는 **4.44×10⁻¹⁶**이다. 기존 CDRI·Layer 1·산식 이력·정책 표의 파일 해시도
실행 전후 동일했다.
