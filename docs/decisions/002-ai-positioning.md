# 002. AI 요소 포지셔닝 — 분석 도구로만, 장식 금지

- 일자: 2026-08-18
- 상태: 채택
- 관련 스토리: G008, G011, G013

## 맥락
팀 내 질문: "데이터 분석 대회인데 AI Agent를 그냥 요새 다 넣어서 넣은 것 아닌가?"
공고 재확인: 제출물 = 분석보고서, 심사 = 창의성·정책 실현 가능성·데이터 분석 적정성 (서비스 완성도 항목 없음).
수상작 재검토: 2025 창원 1위 후보 sLLM 민원응대는 **LLM이 주제 자체**(민원 데이터를 LLM으로 다룸);
2026 경남 "AI 에이전트" 대상은 **AI 창업 부문**(분석 부문 대상은 순수 분석); 빅콘테스트 대상은 군집 분석이 본체, 에이전트는 출력부.
→ "분석 옆에 챗봇"으로 수상한 사례 없음.

## 선택지
1. Agent 3개(재난감시·민원분류·시민안내) + Streamlit 유지 — 트렌드 부합 / "억지로 넣음" 인상, 분석 시간 잠식
2. AI 전부 삭제 — 명확 / 대회명 "AI·데이터"와 정보공개 민원 원문 처리 수단 상실
3. **AI는 분석 도구로만**: 민원 원문 LLM 구조화(방법론) + XGBoost/SHAP(모델), 알림 초안은 활용방안 ≤1p 옵션, 챗봇 삭제
