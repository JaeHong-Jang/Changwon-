# 003. CDRI 5등급 분류 기준 체계 (R1~R5) 채택

- 일자: 2026-08-19
- 상태: 채택 (세부 파라미터는 G010에서 실데이터로 확정)
- 관련 스토리: G010, G013

## 맥락
팀 요청: "등급을 5단계로 분류해서 실제로 위험한 지역을 분류하는 기준 체계 자체를 만들어 주는 것" — 점수 구간이 아니라 행정이 쓸 수 있는 등급 체계를 연구 산출물로.
기존 계획(ANALYSIS_PLAN §5)은 Balica 고정 5등급 + Jenks κ 병기만 있었다.

## 선택지
1. Balica 고정 경계(0.01/0.25/0.5/0.75)만 — 국제 비교 용이 / 창원 실제 발생률과 무관, 등급별 격자 수 예측 불가
2. Jenks 자연구분 5급 — 데이터 적합 / 해석·재현성 약함, 연도 갱신 시 경계 이동
3. **경험적 캘리브레이션**(침수흔적 발생률로 경계 조정, 시간 분할로 out-of-sample 검증) + 1·2안 병기, 결정 규칙 A/B/C, 등급별 대응 행동표

## 결정
3안을 조건부 본안으로: 침수흔적 양성 격자 ≥100 & 시간 분할 가능 → 3안 본안(1·2안 병기); 미달 → Jenks 본안, 3안은 민감도.
등급은 1~5 오름차순(5=최위험), 명칭 R5 최우선 대응 / R4 우선 대응 / R3 점검 강화 / R2 일반 관리 / R1 관찰 (법정 용어·위기경보 상황명·지침 로마숫자와 비충돌).
grade_raw/grade_final 분리(검증은 raw, 대응표는 final). 규칙 A(L1 극단값 하한), B(취약계층 정책 상향), C(기지정 재검토 태그), A·B 합산 ≤2단계.
대응표는 "주기"가 아니라 연간 물량(CCTV 26.1km 등) 배분 우선순위로 기술.

## 근거
- 심사위원 관점 리뷰(하수도사업소 실무+방재공학) 1회: critical 3·major 7·minor 8 → 전부 반영 (`docs/CDRI_GRADE_SYSTEM.md` 말미 기록)
- 환경부 하수관로 상태등급(2025.3 표 6.3·6.4; 2017.6 조치 3단), Balica(2012) 학위논문 5등급, Landis & Koch(1977) κ, Moreira et al.(2021) 등급화 민감도
