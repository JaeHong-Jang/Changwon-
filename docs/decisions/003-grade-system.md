# 003. CDRI 5등급 분류 기준 체계 (R1~R5) 채택

- 일자: 2026-08-19
- 상태: 채택 (세부 파라미터는 G010에서 실데이터로 확정)
- 관련 스토리: G010, G013

## 맥락
팀 요청: "등급을 5단계로 분류해서 실제로 위험한 지역을 분류하는 기준 체계 자체를 만들어 주는 것" — 점수 구간이 아니라 행정이 쓸 수 있는 등급 체계를 연구 산출물로.
기존 계획(ANALYSIS_PLAN §5)은 Balica 고정 5등급 + Jenks κ 병기만 있었다.

## 선택지
1. Balica 고정 경계(0.01/0.25/0.5/0.75)만 — 국제 비교 용이 / 창원 실제 발생률과 무관, 등급별 격자 수 예측 불가
2. Jenks 자연구분 5급 — 데이터 적합 / 해석·재현성 약함, 연도 갱신 시 경계 이동
3. **경험적 캘리브레이션**(침수흔적 발생률로 경계 조정, 시간 분할로 out-of-sample 검증) + 1·2안 병기, 결정 규칙 A/B/C, 등급별 대응 행동표

## 결정
3안을 조건부 본안으로: 침수흔적 양성 격자 ≥100 & 시간 분할 가능 → 3안 본안(1·2안 병기); 미달 → Jenks 본안, 3안은 민감도.
등급은 1~5 오름차순(5=최위험), 명칭 R5 최우선 대응 / R4 우선 대응 / R3 점검 강화 / R2 일반 관리 / R1 관찰 (법정 용어·위기경보 상황명·지침 로마숫자와 비충돌).
grade_raw/grade_final 분리(검증은 raw, 대응표는 final). 규칙 A(L1 극단값 하한), B(취약계층 정책 상향), C(기지정 재검토 태그), A·B 합산 ≤2단계.
대응표는 "주기"가 아니라 연간 물량(CCTV 26.1km 등) 배분 우선순위로 기술.

## 근거
- 심사위원 관점 리뷰(하수도사업소 실무+방재공학) 1회: critical 3·major 7·minor 8 → 전부 반영 (`docs/CDRI_GRADE_SYSTEM.md` 말미 기록)
- 환경부 하수관로 상태등급(2025.3 표 6.3·6.4; 2017.6 조치 3단), Balica(2012) 학위논문 5등급, Landis & Koch(1977) κ, Moreira et al.(2021) 등급화 민감도

## 영향
- ANALYSIS_PLAN §5 등급 부분: Balica 본안 → 조건부 3안 본안(Balica·Jenks 병기)으로 갱신 필요
- G010 산출물 추가: 등급 임계·색상·대응수준 표, `grade_by_dong.csv`, 하수센터별 R5·R4 집계표; 검증에 단조성(효과크기)·κw·지정지역 정합 추가
- 보고서 4장(등급 표·지도 범례)·5장(대응표) 구성 확정; 격자ID·지하층 원표는 비공개 부록

### 판정 결과 — 경계는 안정적이고, 등급 간 위험 차이는 검증되지 않았다

처음의 시간 분할(앞 3개 사상으로 경계, 뒤 3개로 채점)은 점추정으로 단조·p = 4.9e-08·
R5 lift 7.29 였으나 **무효**다. 검증 양성 180격자가 독립 침수 12건이었고 R5 는 1건이었다.

**검증 방법을 LOEO 로 바꿨다** (2026-09-17). 이 결정문의 선택지 3안과 CDRI_GRADE_SYSTEM §1③①
이 미리 정한 대안이다("사상 수가 부족하면 사상 단위 leave-one-event-out 으로 대체").
- 운영 경계는 6개 사상 전부로 맞춘다: 0.306 / 0.433 / 0.586 / 0.837 (R5 76칸)
- 검증 침수 12건 → **46건**
- 추세 판정은 Cochran-Armitage 대신 덩어리 재표본 기울기로 한다(기준 p < 0.01 은 그대로)

결과:
- **경계는 어느 사상을 빼도 거의 같다** — 폴드 간 폭 최대 0.016
- 등급이 오를수록 더 잠길 확률 91.9% — 기준 99% 미달
- R1·R2·R3 발생률 0.47%·0.54%·0.52% — 사실상 같다
- R5 lift 구간 [0.00, 16.85] — 독립 침수 3건

**등급 체계의 위상**: R1~R5 는 검증된 위험 구분이 아니라 **발생률 캘리브레이션 절차로 정한
재현 가능하고 안정적인 행정 우선순위 구간**이다. 한때 "자료가 3단 구조를 뒷받침"한다고 기록했으나
철회한다. R1~R3 통합은 검증 자료를 보고 체계를 고치는 셈이라 지금은 하지 않고 차기 과제로 둔다.

이 제약은 코드가 산출한다 (`h07_cdri._reporting_constraint` — `trend_claim_allowed`,
`monotone_claim_allowed`, `top_grade_above_base` 모두 거짓).

### 본안을 검증 결과로 바꾸지 않는 이유

같은 검증 자료로 Jenks 를 채점하면 단조성부터 깨지고(R4 1.70% < R3 2.12%) 미달 기준이
4개다. 다만 이 비교도 같은 12건에 기대므로 어느 쪽이 낫다는 근거가 되지 못한다. 어떤 경우든
**검증 결과를 보고 본안을 고르지 않는다** — 그러면 검증 자료가 선택에 개입해 out-of-sample 이 아니게 된다. 본안은 이
결정문이 자료를 보기 전에 정한 것이고, 검증은 주장 가능 범위만 정한다.
