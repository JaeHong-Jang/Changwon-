# 결정 기록 (Decision Records)

분석 설계·데이터·방법 선택 중 **되돌리기 어렵거나 결과에 영향이 큰 결정**은 여기 남깁니다.
"왜 이렇게 했는지"를 나중에 심사위원·팀원·미래의 우리가 물어볼 때 답이 되는 문서입니다.

## 규칙
- 파일명: `NNN-짧은-제목.md` (예: `001-layer2-design.md`)
- 한 결정 = 한 파일. 번호는 순차 증가.
- 결정이 뒤집히면 새 파일로 쓰고, 이전 파일 상단에 `Superseded by NNN` 표기.
- 하네스 스토리 checkpoint 시 관련 결정 파일 경로를 evidence에 포함.

## 템플릿

```markdown
# NNN. 제목

- 일자: YYYY-MM-DD
- 상태: 채택 | 폐기 | Superseded by NNN
- 관련 스토리: G0NN

## 맥락
어떤 상황·증거 때문에 결정이 필요했는가

## 선택지
1. A — 장점 / 단점
2. B — 장점 / 단점

## 결정
무엇을 골랐고, 결정적 근거는 무엇인가

## 영향
이 결정으로 바뀌는 것 (데이터·코드·보고서 서술·리스크)
```
