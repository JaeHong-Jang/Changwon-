## 지위

- 저자용 초고다. 투고하지 않았다. 저자·소속·기여·사사는 비어 있다.
- 새 분석은 없다. 수치는 모두 M1~M4·M4S·M6 와 9/24 홀드아웃·라벨 감사·CDRI·예보 run 의 저장 산출에서 왔다.
- 중심 주장: 사전 고정 L1 게이트 탈락의 강건성(32 설정)과 격자 AUC 분해식·그 일반성. C-b 는 폐기, M5 는 생략, CDRI·예보는 부록.
- 2022~2024 흔적으로 채점한 L1 게이트 외의 모든 설계는 post-hoc 이다.
