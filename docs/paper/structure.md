# NHESS 원고 구성 (M7)

> 원고: `manuscript_en.md` (초고 v0.1). 절차: `docs/q1/M7_protocol.md`.
> 이 문서는 절마다 무엇을 주장하고 어떤 근거(과제·run)를 쓰는지, 그림·표를 어디에 두는지, NHESS 투고 요건을 어디까지 채웠는지 적는다.

## 1. 논문의 뼈대

| 층 | 내용 | 근거 과제 |
|---|---|---|
| 중심 주장 1 | 동결 지수 L1 의 사전 게이트 탈락, 32 라벨 설정에서 유지 (V1). V2 참조 통과·한 사상 지배를 같이 보고 | 홀드아웃 run, M4 |
| 중심 주장 2 | 격자 AUC = 객체 기여 가중평균 (식 1), 세 항 분해 (식 2), 공분산 형태 (식 3), 지수 기울임 (식 4) | M4, M4S |
| 중심 주장 3 | 차이는 크기 분산 × 크기–탐지 결합에서 생긴다 (가상 자료, 사전 판정 "일반성 지지") | M4S |
| 결과 (보조) | 자명 기준선 = 학습 모형 → C-b 폐기. 사상 단위 불확실성. 중첩 선택 | M1, M2, M3 |
| 결과 (현상) | 강수 기후 축 역방향 (원인 미확정) | 홀드아웃 run |
| 방법 (신뢰) | 계산 전 절차 커밋, run_id, 재실행, 연대표 | M6 |
| 부록 | CDRI, 예보 | posthoc_h run, FORECAST_RESULTS |
| 폐기·생략 | C-b 폐기, M5 생략 (재현 주장 없음) | M1, CLOUD_TASKS |

제목은 "평가 설계가 판정을 뒤집는다"를 쓰지 않는다 (M4 리더 판단 1). V1 판정은 유지되고 AUC 크기와 V2 가 바뀐다.
