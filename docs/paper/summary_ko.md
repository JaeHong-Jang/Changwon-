## 한 문단 요약

국토부 지침 구조로 만든 창원시 침수지수 L1 은 산식을 동결(2026-09-08)한 뒤 받은 2022~2024 침수흔적에서 사전 게이트(격자 AUC ≥ 0.70, 상위 20% 포착 ≥ 0.50)를 탈락했다 (0.436 / 0.073).
이 탈락은 라벨 규칙 8개 × 격자 크기 4개 = 32 설정 모두에서 유지된다. 포착은 어느 설정에서도 0.412 를 넘지 않는다.
다만 사상별 중앙값 게이트는 참조 설정에서 통과한다. 합동 판정은 사실상 2024-09-20 한 사상의 판정이기 때문이다 (양성 격자 1,267칸 중 1,254칸).
격자 AUC 는 폴리곤별 기여의 가중평균이라는 항등식을 유도했다. 가중치는 폴리곤이 만든 양성 격자 질량이다.
L1 의 격자 0.436 과 객체 0.712 의 차이 −0.276 은 크기 가중 −0.198 과 소실 −0.078 로 정확히 나뉜다.
가중치의 97.6% 가 농업 폴리곤에 있고, 유효 폴리곤 수는 196개 중 25.7개다.
가상 자료 115 시나리오에서 0.1 이상의 격자–객체 차이는 크기 분산과 크기–탐지 결합이 **함께** 있을 때만 생겼고, 닫힌 식 Δ\* 가 부호와 크기를 예측했다.
경사 단독 기준선이 학습 지형 모형과 같은 수준이어서 (사상 중앙값 0.872 대 0.855) "학습 모형이 더 낫다"는 주장은 버렸다.

## 연구 질문과 답

| 질문 | 답 | 근거 |
|---|---|---|
| Q1. L1 게이트 탈락이 라벨 규칙·격자 크기에 달려 있는가? | 합동 홀드아웃 판정(V1)은 32 설정 모두 탈락. 사상별 중앙값 판정(V2)은 참조에서 통과하고, 실질 뒤집힘 9개는 모두 규칙과 크기(500·1000 m)를 함께 바꾼 설정이다. 관행 규칙만 바꾸거나 크기만 바꾸면 10개 점수 모두 실질 뒤집힘 0 | M4 |
| Q2. 격자 AUC 와 객체 AUC 는 왜 다른가? 창원 고유인가? | 격자 AUC = 객체 기여의 가중평균 (오차 1.6e-15). 차이 = 크기 가중 + 객체 안 + 소실. 크기 가중 항 = ρ·sd·√(n_S/n_eff − 1). 가상 자료에서 사전 판정 "일반성 지지" | M4, M4S |
| Q3. 학습 모형은 자명 기준선보다 나은가? | 격자 AUC 로 구분되지 않는다 → C-b 폐기. 사상 수준 구간도 구분하지 못한다. 설정 선택을 이전 사상 안으로 넣어도 결론 같다 | M1, M2, M3 |

## 주요 수치

### 게이트 (합동 홀드아웃, 참조 설정 `f10`·100 m)

| 점수 | 격자 AUC | 덩어리 AUC | 상위 20% 포착 | 게이트 |
|---|---:|---:|---:|---|
| L1 (동결) | 0.436 [0.386, 0.596] | 0.603 [0.544, 0.661] | 0.073 | 탈락 |
| 시 침수예상도 | 0.450 | — | 0.026 | 탈락 |
| 과거 흔적 근접도 | 0.532 | — | 0.205 | 탈락 |

- 개발 6사상에서는 L1 이 0.750 [0.633, 0.863] / 0.544 로 통과했다 (홀드아웃 입수 전, 9/16).
- 32 설정의 L1 V1 여유: −0.088 (`rep_point`·100 m, 0.694 / 0.412) ~ −0.500.
- 100 m 안에서 규칙만 바꿔도 L1 AUC 는 0.394~0.694 로 움직인다 (범위 0.300). RF 는 0.023.

### 분해 (L1, 합동 홀드아웃, 100 m)

| 규칙 | 격자 AUC | 크기 가중 | 객체 안 | 소실 | n_eff |
|---|---:|---:|---:|---:|---:|
| `f10` (참조) | 0.436 | −0.198 | −0.000 | −0.078 | 25.7 |
| `rep_point` | 0.694 | −0.015 | −0.003 | 0.000 | 177.4 |
| `soft` | 0.403 | −0.306 | −0.003 | 0.000 | 19.6 |

- 객체 AUC 는 모든 규칙에서 0.712 다.
- 가중치 몫: 2024-09-20 0.988, 농업 폴리곤 0.976, 20,000 m² 이상 0.898, 도심 57개 0.002 (생존 7개).
- 폴리곤 1표 AUC: 도심 0.910 [0.879, 0.938], 농업 0.608 [0.574, 0.642].
- 생존율 (`f10`, 100 m): 홀드아웃 0.663, 도심 0.123 (홀드아웃 57개 기준), 500 m² 미만 0.093. 개발 142개는 0.958.

### 가상 자료 (115 시나리오 × 복제 200)

- 결합 없음(β = 0) 21개: 차이 중앙값 |·| ≤ 0.006 (`f10`), 0.009 (`soft`).
- |Δ\*| ≥ 0.15 인 15개: 모두 복제의 절반 이상에서 |차이| ≥ 0.1 이고 부호가 β 와 같다. |Δ\*| < 0.06 인 8개: 모두 그렇지 않다.
- 실현 차이 / Δ\* (σ ≤ 2): `soft` 0.94, `f10` 0.74.
- 창원 기준점 (post-hoc): 50쌍 Spearman 0.885. L1 합동 홀드아웃 σ̂ 2.46, β̂ −0.80, Δ̂\* −0.406 (관측 −0.276).
- 틀린 보조 예측: `rep_point` 는 큰 객체가 많은 경관(σ = 3, β = +1)에서 −0.0505 로 0.05 를 넘었다. 편향 없는 대안이 아니다.
- 창원의 V1(0.436)–V2(0.791) 대비는 "모든 사상이 같은 β" 생성기로는 재현되지 않는다. 가중치 98.8% 를 가진 사상만 강한 음의 결합(β̂ −0.83)을 가진 구성에서 나온다.

### 기준선·사상 통합·중첩 선택 (post-hoc)

- 7사상 격자 AUC 중앙값: 경사 0.872, RF-F1 0.855 → 사전 규칙상 C-b 폐기. 사상별 짝 차이 중앙값은 RF 쪽 +0.030 (7사상 중 4사상 RF 우세). 두 요약이 다른 쪽을 가리킨다는 것도 쓴다.
- 사상 통합 (logit): RF − 경사 −0.141 [−0.907, +0.625]. 객체 AUC 는 개발 −0.131, 홀드아웃 +0.186, 둘 다 구간이 0 을 포함 → "RF 가 객체 순위를 더 잘 맞힌다"고 쓰지 않는다.
- 개발 6사상 통합 격자 AUC: 경사 0.897, HAND(OSM) 0.884, RF 0.876, L1 0.762. 예측구간 하한이 0.70 이상인 점수는 HAND 두 가지뿐.
- 홀드아웃 격자 AUC 는 k = 2 사상이라 통합 구간이 거의 [0, 1] 이다. 단일 "홀드아웃 AUC" 로 쓰지 않는다.
- 평지(경사 ≤ 5°) 안에서는 어떤 점수도 중앙값 0.70 에 못 미친다 (최고 경사 0.693). "지형 모형이 잘 맞힌다"의 상당 부분은 산지 대 평지 구분이다.
- 중첩 선택: 고정 0.873 → 중첩 0.865 (차 0.008, 규칙 0.02 이내). 보조: 모델군까지 고르면 0.841 (−0.032), 포착 0.902 → 0.761. 중첩 선택은 네 번 모두 시 침수예상도를 뺀 F0 을 골랐다.

### 강수 기후 축과 재현성

- 노출 축 단독 격자 AUC: 개발 0.389, 홀드아웃 0.147 (둘 다 0.5 아래). 현상 기술만 한다. 원인은 사상 강우 자료 없이 확정할 수 없다.
- 커밋 상태 재실행: 게이트 해시·게이트 값 동일. 그러나 사전 규칙상 "불일치" (면적·객체 지표 1,966행이 최대 1.8e-12 차이, 재투영 마지막 자리로 추정, 확정 못 함).

## 원고 구성 (NHESS)

1. 서론: 지수 검증 부족, 평가 설계가 수치를 바꾼다는 선행, 폴리곤 → 격자 변환은 지지 변경(MAUP) 문제, 세 질문과 기여, **증거의 지위** (사전 동결 지수의 사후 확보 독립 사상 평가).
2. 연구 지역·자료: 창원 100 m 격자, L1 산식, 흔적 (표 1), 연대표·입력 시점.
3. 방법: 점수 10개, 라벨 규칙 8 × 격자 4, 게이트 판정 V1·V2, **분해식 (식 1~4)**, 가상 시연, 자명 기준선·어려운 음성, 사상 통합·중첩 선택, 절차·출처 관리.
4. 결과: 4.1 게이트 탈락 (표 2) → 4.2 분해 (표 3~5) → 4.3 일반성 (표 6, 그림 4) → 4.4 기준선 (표 7) → 4.5 강수 축 → 4.6 재현성.
5. 논의: 탈락이 말하는 것과 말하지 않는 것, 격자 AUC 는 가중치 선택이다 (보고 권고 4가지), 철회한 주장, 한계.
6. 결론.
- 부록: A 유도, B CDRI, C 예보, D 연대표, E 보충 표.

## 부록으로 내린 것

- **CDRI (H·E·V·D):** 거주 격자 10,202칸, 홀드아웃 양성 102칸. CDRI 격자 AUC: H = L1 0.340, 민감도 축 0.392, RF(2019까지) 0.480, RF 동결 0.496. H = L1 과 H = RF 의 TOP 20 중첩 5/20.
  우선순위 검증에는 피해·119 같은 결과 자료가 필요하다. 이 수치를 우선순위 검증으로 해석하지 않는다.
- **예보:** 전날 예보 로지스틱 사상 제외 교차검증 BSS 0.055 [−0.249, 0.210] → 주 판정 1 미충족. 결합 확률 BSS 0.0002 [−0.0038, 0.0017] → 주 판정 2 미충족.
  호우경보는 기록 사상을 모두 잡았다 (오경보 50~58%).

## 쓰지 않은 것 (금지 표현과 철회한 주장)

- 전향적·사전등록 검증이라고 쓰지 않는다. 사상은 지수 설계 전에 일어났고, 입수만 동결 뒤다. 절차 커밋은 내부 기록이지 외부 등록이 아니다.
- 학습 모형(RF)이 검증됐다, 지침형 지수보다 낫다고 쓰지 않는다. 홀드아웃 RF 값(0.843 / 0.763)은 post-hoc 설계이고 한 사상이 지배한다.
- 10사상 일관이라고 쓰지 않는다. 격자 AUC 가 있는 홀드아웃 사상은 2개다.
- 강수 역방향의 원인을 확정하지 않는다.
- CDRI 가 우선순위를 식별한다고 쓰지 않는다. 예보가 침수 예측을 개선한다고 쓰지 않는다.
- 도심 소실률은 "홀드아웃 도심 57개 중 12.3% 생존"처럼 대상을 붙여 쓴다.
- "평가 설계가 판정을 뒤집는다"는 제목으로 쓰지 않는다. M4 결과로는 판정(V1)이 유지되고 AUC 크기가 바뀐다.
- 다도시 재현(M5)은 하지 않았다. 재현을 주장하지 않고 한계로 적는다.
