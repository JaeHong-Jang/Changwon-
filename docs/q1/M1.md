## 결과 요약

- **사전 판정: C-b(지형 모형 우위) 주장 폐기.** 시험 사상 7개(E\*) 격자 AUC 중앙값: 경사 단독 0.872, 시간순 RF-F1 0.855.
  경사 ≥ RF − 0.02 이다.
- 경사 단독은 개발 사상 6개와 홀드아웃 2개(양성 격자 있는 사상) 모두 사전 게이트(AUC ≥ 0.70, 상위 20% 포착 ≥ 0.50)를 통과한다.
  HAND·TWI 단독도 같다. 동결 L1 은 격자 AUC 게이트를 8사상 중 5사상만 통과한다.
- 보조 결과 두 가지는 RF 쪽이다 (판정에 쓰지 않는다). 사상별 짝 차이(RF − 경사)의 중앙값은 +0.030 이고,
  객체 AUC 중앙값은 RF 0.856, 경사 0.819 (9사상)다. 평지층에서는 경사 0.707, RF 0.654 다.

## 한계·미확인

- **post-hoc.** 홀드아웃 결과를 본 뒤 설계했다. 주 판정은 7사상 중앙값이다. 사상 하나가 바뀌면 판정이 바뀔 수 있다
  (경사 0.872 와 RF − 0.02 = 0.835 의 차이 0.037). 사상 수준 불확실성 통합은 M2 에서 한다.
- RF-F1 의 설정(특징·하이퍼파라미터)은 개발 6사상 전체 CV 로 골랐다. 그래서 시간순 RF 도 미래 사상 정보를 설정 선택에 쓴 셈이고,
  RF 에 유리한 쪽의 편향이다. 중첩 선택은 M3 에서 다룬다.
- AGRI 층은 토지피복이 아니라 "불투수 < 0.1, 경사 ≤ 5°, 내륙수 < 0.5" 대리 정의다. 논·밭인지 확인하지 않았다.
- 경사·TWI·HAND 는 90 m DEM 을 100 m 격자에 bilinear 로 올린 값이다. 평지층 안의 미세 지형 구분력은 DEM 해상도가 제한한다.
- 상대고도의 역방향(포착 0.003)은 원인을 확인하지 않았다. 확인하지 않은 가설: 반경 초점평균에 바다·저지 칸이 들어가
  해안 평지가 "주변보다 높게" 계산된다. 방향은 사전 고정대로 두었다.
- HAND 는 절차 첫 커밋 뒤, AUC 계산 전에 흐름 방향 규칙을 한 번 보정했다 (평탄 칸 문제, 절차 문서 보정 절).
  보정 전 규칙으로는 계산하지 않았다.
- 분석 격자의 19.2% 는 OSM 하천에 닿지 않고 해안·격자망 가장자리에서 흐름이 끝난다. 이 칸의 HAND 는 흐름 끝 칸(대개 해수면 근처) 위 높이다.
- 공식 run 전에 두 번 더 실행했다. 코드가 커밋되기 전의 개발 전용 점검 실행(`--dev-only --n-boot 50`, dirty)과,
  판정 표 정렬 경고를 고치기 전의 전체 실행(`m1_20260926T160628Z_225ef98`)이다. 둘 다 판정은 같았고, 산출물은 저장소에 넣지 않았다.
