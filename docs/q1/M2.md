  다른 짝에서도 음의 상관이 있다 (예: 상대고도와 경사, 사상별 −0.55 ~ −1.00).

## 한계·미확인

- **post-hoc.** M1 사상별 결과(홀드아웃 포함)를 본 뒤 설계했다. 새 자료로 검증한 것이 아니다.
- **SE 는 근사다.** M1 이 재표본 값을 저장하지 않아 백분위 구간에서 되돌렸다. 개발 사상에서만 점검했다(S4).
  홀드아웃 사상(2023-08-10 은 덩어리 3개)의 SE 근사 오차는 확인하지 않았다. 홀드아웃 원본을 다시 읽지 않기로 했기 때문이다.
- **덩어리 재표본은 음성 격자를 고정한다.** SE 에 배경 표본 변동은 없다. 객체 AUC 구간은 사상 안 폴리곤 재표본이다.
- **무작위효과 가정.** 사상을 "교환 가능한 호우 모집단의 표본"으로 본다. 같은 도시·같은 격자이고, 흔적 출처가 연도마다 다르다
  (행안부 API 2006~2019, 시 2025, 시 정보공개 2022~2024). 사상 효과의 정규성은 k ≤ 6 으로 확인할 수 없다.
- **k = 2 홀드아웃.** 수정 HKSJ(t(1))는 구간이 거의 [0, 1] 이다. DL + Wald(S1)는 좁지만, 사상이 적을 때 포함 확률이 명목보다 낮다고 알려져 있다 (IntHout et al. 2014).
- **추정량 불일치.** 이질성이 한두 사상에 몰린 행에서 REML τ², DL 기반 I², Q-profile 구간이 서로 어긋난다 (§2 †, 5행 표시).
- **짝 상관.** 주 분석 ρ = 0 은 개발 5사상 중 1사상에서 짝 차이 SE 를 작게 잡았다 (§8). 홀드아웃 사상의 실제 상관은 모른다.
- RF-F1 설정은 개발 6사상 전체 CV 로 골랐다 (M1 과 같은 한계, M3 에서 다룬다). 상위 20% 포착률은 구간이 없어 통합하지 않았다.
- 문헌 DOI 는 출판사·PubMed URL(웹 검색)로 확인했다. Crossref API 는 클라우드 네트워크 정책(403)으로 막혀 쓰지 못했다.
  `docs/research_reports/doi_check.tsv` 에는 아직 없다.
