# M3 절차 — 중첩 시간순 교차검증 (계산 전 고정)

> 과제 정의: `docs/CLOUD_TASKS.md` M3. 규칙: `AGENTS.md` §2·§6·§8.
> 이 문서는 **설정 공간·안쪽 선택 규칙·바깥 채점·판정 규칙을 계산 전에 고정**하려고 커밋한다.
> 이 커밋 전에는 M3 의 어떤 선택 점수(안쪽 LOEO 지표)나 바깥 AUC 도 계산하지 않았다.
> 계산 전에 본 것 (라벨 지표 아님):
> - 개발 사상별 양성 격자 수 (`trace_ev_<연도>` 합): 2006 107, 2012 206, 2014 132, 2016 170, 2019 56, 2025 25.
> - 동결 모델 `.omc/benchmark/final_model.joblib` 의 파라미터가 `make_model("random_forest", {"max_depth": 4, "min_samples_leaf": 400})` 와 같다.
> - 동결 벤치마크 `tuning_audit.json` 의 LOEO 부분별 선택 파라미터 (§4.3 재현 확인 대상을 고르려고 봤다).

## 0. 지위와 질문

- **post-hoc.** M1 결과(C-b 폐기: 경사 0.872, 시간순 RF-F1 0.855)와 홀드아웃 결과를 본 뒤 설계했다.
  홀드아웃은 채점에만 쓰고, 선택·학습에는 쓰지 않는다 (AGENTS §2-2).
- **질문.** 고정 구성 walk-forward(M1 의 `rf_F1_wf`, `artifacts/posthoc/20260926/walkforward.py`)는
  모델군·특징집합·하이퍼파라미터를 개발 6사상 전체 CV 로 골랐다. 여기에는 시험 사상 자신과 그 뒤 사상, 2025 가 들어 있다.
  시험 사상 **이전** 사상만으로 설정을 골랐다면 바깥 성능이 얼마나 달라지는가.

## 1. 시험 사상과 이전 사상

- 시험 사상은 M1 과 같다. 개발은 `event_date` 연도가 2006·2012·2014·2016·2019·2025 인 흔적이다 (날짜 없는 흔적은 뺀다).
  홀드아웃은 `storm_id` 별 4사상이다.
- 이전 사상 P(T) 는 M1 `prior_years` 와 같다. 시험 연도보다 이른 개발 사상이고, 2025 는 뺀다.

| 시험 사상 | P(T) | \|P\| | 중첩 선택 상태 |
|---|---|---:|---|
| 2006 | — | 0 | **학습 불가** (고정·중첩 모두 없음) |
| 2012 | 2006 | 1 | **선택 불가** (고정 구성만 있음) |
| 2014 | 2006, 2012 | 2 | 선택 |
| 2016 | 2006, 2012, 2014 | 3 | 선택 |
| 2019 | 2006, 2012, 2014, 2016 | 4 | 선택 |
| 2025, 홀드아웃 4사상 | 2006, 2012, 2014, 2016, 2019 | 5 | 선택 (같은 P 라 같은 설정) |

- 학습 라벨은 `layer1_flood.gpkg` 의 `trace_ev_<y>` (y ∈ P) 합집합이고, 전 격자 75,400칸을 쓴다.
  P 밖 사상(미래 개발 사상, 2025, 홀드아웃)의 라벨은 안쪽 선택과 바깥 학습 어디에도 쓰지 않는다.
  미래 사상의 양성 격자도 학습에서는 음성이다 (M1 과 같다).

## 2. 설정 공간 (`.omc/benchmark/prespec.json` 격자)

- 특징집합: `features` 의 F0·F1·F2. 모델 후보: `candidates` (4 모델군 × 2 후보). 고정 파라미터: `fixed_parameters`.
  실행할 때 이 세 항목이 코드 상수 `FEATURES`·`CANDIDATES`·`FIXED_PARAMS` 와 같은지 확인하고, 다르면 멈춘다.
- **주 변형 `nested_rf`.** 모델군은 동결 선택(`random_forest`)으로 둔다. 특징집합 3 × RF 후보 2 = **6 설정**이다.
  과제 정의("특징집합과 하이퍼파라미터를 고른다")를 문자 그대로 따른 것이다.
- **보조 변형 `nested_all`.** 모델군까지 포함한 전체 격자다. 특징집합 3 × (4 모델군 × 2 후보) = **24 설정**이다.
  동결 선택은 모델군도 전체 개발 CV 로 골랐으므로 이것도 함께 본다.
- 선언 순서(동점 처리): 특징집합 F0 → F1 → F2. 그 안에서 모델군 `ridge` → `frequency_ratio` → `random_forest` → `xgboost`.
  그 안에서 후보는 `candidates` 순서다. 벤치마크 `ranking` 의 순서와 같다.
- **고정 구성**은 `random_forest` / F1 / `{max_depth: 4, min_samples_leaf: 400}` 이다 (동결 모델과 같은 파라미터).
  두 변형 모두 이 설정을 후보로 포함한다.

## 3. 안쪽 선택 — 이전 사상 안의 LOEO

각 P(\|P\| ≥ 2) 마다 P 의 사상 열만으로 벤치마크 LOEO 기계(`src/models/folds.py`)를 그대로 쓴다.

- `event_folds`: 뺀 사상 e 의 양성 격자는 학습에서 전부 뺀다 (다른 P 사상과 겹친 양성 포함).
  시험 = e 의 양성 + P 어느 사상에서도 양성이 아닌 격자.
- `loeo_groups`: e 를 뺀 P 라벨로만 공간 그룹과 배경 3분할을 만든다 (e 라벨과 무관).
- `crossfit_event`: 시험 음성은 배경 그룹별로 학습에서 빼고 교차 예측한다. e 의 양성은 세 모델 예측의 평균이다.
- 설정마다 `make_model(모델군, 후보)` 를 각 학습 부분에 적합한다. 안쪽에서 하이퍼파라미터를 다시 튜닝하지 않는다
  (하이퍼파라미터가 설정의 일부다). 전처리(중앙값 대치, ridge 표준화)는 파이프라인 안에서 학습 부분에만 맞춘다.
- 지표: `score_metrics` 의 `cluster_auc` (벤치마크 선택 규칙과 같은 지표). `grid_auc`·`top20_capture` 는 기록만 한다.
- **선택 점수** = P 의 뺀 사상별 `cluster_auc` 의 비가중 평균. 최대인 설정을 고른다. 동점은 §2 선언 순서로 푼다.
- 뺀 사상의 시험 집합에 양성이나 음성이 없으면 실행을 멈춘다.
- 병렬도: `threadpool_limits(2)`, 모델 고정 파라미터의 `random_state=42`·`n_jobs=2` 그대로.

## 4. 바깥 채점

### 4.1 점수

고른 설정을 P 전체의 라벨 합집합으로 전 격자에 적합한다 (M1 `trained_before` 와 같은 방식). 그리고 전 격자에 점수를 매긴다.

| 이름 | 정의 | 역할 |
|---|---|---|
| `rf_F1_wf` | 동결 모델을 clone 해 P 로 재학습 (M1 과 같은 정의) | 고정 구성 walk-forward |
| `nested_rf` | §2 주 변형에서 P 안 LOEO 로 고른 설정, P 로 재학습 | **주 비교 대상** |
| `nested_all` | §2 보조 변형에서 고른 설정, P 로 재학습 | 보조 |
| `slope_neg` | −`slope_deg` | M1 판정 재확인용 자명 기준선 |

- 2006(학습 불가)은 세 학습 점수가 모두 없다. 2012(선택 불가)는 `rf_F1_wf` 만 있고, 두 중첩 점수는 채점하지 않는다.
  표에는 "선택 불가"·"학습 불가" 상태를 적는다.

### 4.2 평가

M1 §3·§4 와 같다.
`V.evaluate(scores, layer, polys, strata=M1 층, background_mask=~touched, min_overlap=0.10, n_boot=1000, seed=42)` 이다.
층은 ALL·FLAT·URBAN·AGRI·UNIVERSE 이고, `touched` 는 개발·홀드아웃 어느 흔적과도 닿은 격자다.
보고 행은 격자 AUC, 상위 20% 포착, 객체 AUC, 덩어리 AUC 다 (M1 `KEEP` 과 같음). 최소 표본도 M1 과 같다:
층×사상에서 양성 격자 < 5 이면 격자 지표를, 폴리곤 < 3 이면 객체 지표를 중앙값에서 뺀다.

### 4.3 재현 확인 (실행 안에서 자동)

1. **LOEO 기계 재현.** P = 개발 6사상 전체, RF/F1/(4, 400) 으로 안쪽 LOEO 함수를 돌린다.
   동결 벤치마크가 세 부분 모두 (4, 400) 을 고른 뺀 사상(2014, 2025)의 `cluster_auc`·`grid_auc`·`top20_capture` 가
   `.omc/benchmark/results_dev.csv` (`random_forest`, F1, `loeo`) 와 최대 절대차 1e-9 안에서 같아야 한다. 다르면 실행을 멈춘다.
   개발 라벨만 쓰는 코드 검사이고, 선택에는 쓰지 않는다.
2. **M1 재현.** `rf_F1_wf`·`slope_neg` 의 지표 값(`value`)을 M1 공식 run `m1_20260926T160821Z_a181f6c` 의 `metrics_long.csv` 와 비교한다.
   같은 사상·층·단위·지표에서 비교하고, 최대 절대차를 `summary.json` 에 기록한다. 1e-9 를 넘으면 판정을 "재현 실패"로 둔다.

## 5. 사전 판정 규칙

- **사상 집합 E_nest.** ALL 층 격자 AUC 에서 `rf_F1_wf` 와 `nested_rf` 가 모두 있고 양성 격자가 5칸 이상인 시험 사상이다
  (개발·홀드아웃 합산). M1 에 비추어 예상하는 E_nest 는 2014·2016·2019·2025·2023-08·2024-09 의 6사상이다.
  이 가운데 뒤의 3사상은 같은 P 라 같은 설정을 쓴다. 독립적인 선택은 4번(\|P\| = 2, 3, 4, 5)이다.
- m_fixed = E_nest 에서 `rf_F1_wf` 격자 AUC 의 중앙값, m_nested = 같은 사상에서 `nested_rf` 격자 AUC 의 중앙값.
- **주 판정 (고정 구성의 설정 선택 낙관):**
  - **m_nested < m_fixed − 0.02 이면** "고정 구성 walk-forward 는 설정 선택에 쓴 미래 정보로 0.02 넘게 낙관적이다"로 판정한다.
    그러면 M1·walkforward 의 RF 수치를 인용할 때 중첩 수치를 주 수치로 함께 싣는다.
  - 그렇지 않으면 "설정 선택의 미래 정보가 격자 AUC 중앙값을 0.02 넘게 올리지 않았다"고만 쓴다.
    m_nested > m_fixed + 0.02 이면 그 사실을 그대로 적는다. 중첩 선택이 낫다는 주장으로 쓰지 않는다.
- **M1 판정 재확인 (사전 고정, 판정 문구는 따로):** E_nest 에서 m_slope ≥ m_nested − 0.02 이면
  "M1 의 C-b 폐기 판정은 중첩 선택에서도 유지된다"로 적는다. 아니면 "M1 판정이 설정 선택 방식에 달려 있다"로 적는다.
  어느 쪽이든 M1 의 사전 판정 자체는 바꾸지 않는다 (재해석은 post-hoc 이다). 같은 E_nest 에서 경사 대 고정 구성도 함께 싣는다.
- **보조 (판정에 쓰지 않는다, 그대로 보고):**
  - `nested_all` 로 같은 두 비교.
  - 개발만·홀드아웃만, 객체 AUC, 상위 20% 포착, FLAT 층.
  - 사상별 짝 차이(고정 − 중첩)의 중앙값.
  - P 별 선택된 설정과 고정 구성의 안쪽 순위·선택 점수.
  - 선택 낙관: 고른 설정의 안쪽 선택 점수와 바깥 격자·덩어리 AUC 의 차이.
  - 2012(선택 불가) 행은 고정 구성 값만 싣는다.
- 결과를 본 뒤 규칙·설정 공간·지표를 바꾸면 `post-hoc` 으로 표기하고, 이 규칙의 결과를 함께 싣는다.
