## 결과 요약

- **사전 판정: 일반성 지지.** 주 예측 P2·P3·P3′ 가 모두 맞았다 (`decision.json`). 크기–탐지 결합이 없으면(β = 0) 21개 시나리오 모두 차이 중앙값이 |0.009| 이하다.
  |Δ\*| ≥ 0.15 인 15개 시나리오는 `soft`·`f10` 모두 `벌어짐`(P10 ≥ 0.5)이고 부호가 β 와 같다. |Δ\*| < 0.06 인 8개는 모두 `없음` 이다.
- **공식 Δ\* 가 실현 차이를 예측한다.** σ ≤ 2 에서 `soft` 실현 차이 / Δ\* 는 중앙값 0.94 (0.86~1.06, 24개), `f10` 은 0.74 (0.63~0.83) 다. 칸 수 가중이 면적 가중보다 덜 집중되기 때문이다.
  크기 가중 항 = ρ·sd·√(n_S/n_eff − 1) 공분산 형태는 150,396행에서 최대 오차 1.4e-12 로 성립한다. 격자 AUC 분해 항등식은 최대 7.0e-15 다.
- **창원 기준점:** M4 의 (사상, 점수) 50개에서 Δ̂\* 와 관측 `f10` 차이의 Spearman 상관 0.885. L1 합동 홀드아웃은 σ̂ = 2.46, β̂ = −0.80 → Δ̂\* = −0.406 (관측 −0.276).
  창원 L1 의 큰 차이는 "넓은 크기 분포 + 큰 객체일수록 낮은 점수"가 함께 있을 때 생기는 일반적 결과다. 창원 고유의 성질이 아니다.

### 게이트 판정이 바뀌는 조건 (`summary_by_scenario.csv`, `flip_conditions.csv`)

- AUC 단위 뒤집힘은 정의상 차이가 Ã 와 0.70 의 거리보다 크고 방향이 반대일 때다. `flip_conditions.csv` (`f10`, 모든 복제): Ã − 0.70 ∈ [0, 0.05) 이고 차이 ∈ [−0.2, −0.1) 이면 뒤집힘 1.00, 차이 ∈ [−0.1, 0) 이면 0.54.
- **묶음 D (σ = 1.5, n = 200, `f10`):** 객체 게이트와 격자 게이트가 반대가 되는 비율.
  - μ0 = 1.45 (객체 AUC 0.79~0.83, 객체 게이트 100% 통과): β = −1 에서 격자 게이트 통과 0% → 단위 뒤집힘 1.00, β = −0.5 에서 0.62 (`soft` 0.86).
  - μ0 = 0.55 (객체 AUC 0.61~0.64, 객체 게이트 0~0.5% 통과): β = +0.5 에서 격자 통과 95.5% → 뒤집힘 0.95, β = +1 에서 1.00.
  - β = 0 에서는 μ0 = 1.45 뒤집힘 0, μ0 = 0.55 는 0.03.
  - 결론: **객체 단위가 게이트 한쪽에 있고, 크기–탐지 결합이 반대 방향이면 격자 단위 판정이 뒤집힌다.** 결합 방향이 같으면 뒤집히지 않고 여유만 커진다.
- 묶음 A (μ0 = 0.95, 객체 AUC 0.66~0.75 로 게이트 근처): β = −0.5 에서 격자 게이트 통과는 σ = 0.5 의 0.23 에서 σ ≥ 1.5 의 0 으로 떨어진다. 객체 게이트 통과는 0.33~0.82 다.
  객체 포착(0.48~0.53)도 0.50 근처라 β = 0 에서도 단위 뒤집힘이 0.10~0.46 생긴다 (게이트 근처 잡음).
- 규칙 뒤집힘 비율(규칙 × 시나리오)은 `summary_by_scenario.csv` 의 `rule_flip_rate` 에 있다.

### 묶음 B: 여러 사상의 합동 라벨 (σ = 1.5, n̄ = 50, `f10`)

- 사상별 최대 가중치 몫 (S5 맞음): E = 4 `equal` 0.30~0.31, `skewed` 0.56~0.60. E = 10 `equal` 0.14, `skewed` 0.39~0.42.
- 합동 라벨의 격자–객체 차이는 단일 사상과 같다 (β = −0.5 에서 −0.123~−0.129, β = +0.5 에서 +0.094~+0.102).
- **V1(합동) 대 V2(사상별 중앙값):** 격자 AUC 차이 중앙값 |V1 − V2| ≤ 0.012. |V1 − V2| ≥ 0.1 인 복제 비율은 `skewed`·υ = 0.5 의 β ≤ 0 에서 0.15~0.20, 나머지 ≤ 0.05.
  V1·V2 게이트 뒤집힘은 β = 0 (격자 AUC 0.72~0.74 로 게이트 근처)에서 0.11~0.31, β = ±0.5 에서 ≤ 0.12 다.
- 모든 사상이 같은 β 를 가지면 사상을 합쳐도 V1 과 V2 는 거의 같다. 창원의 V1 0.436 대 V2 0.791 (M4)은 이 생성기로 재현되지 않는다.
  창원에서는 가중치 98.8% 를 가진 2024-09-20 한 사상만 강한 음의 결합을 가진다 (아래 기준점: 2024-09-20 L1 β̂ −0.83, 개발 사상 L1 |β̂| ≤ 0.17). 사상마다 β 가 다른 경우는 시뮬레이션하지 않았다.

## 한계·미확인

- **생성 모형의 단순화.** 객체 신호를 닿은 칸 전체에 같은 크기로 준다. 그래서 객체 안 항이 구성상 0 에 가깝다 (−0.001~−0.011). 실제 자료의 객체 안 효과(가장자리 희석 등)는 이 시연으로 말할 수 없다. 창원 L1 의 객체 안 항도 −0.000 이었다.
- 객체 배치가 공간적으로 무작위이고(저지대 군집 없음), 배경 점수장은 정상 가우스장 하나(평활 2칸)다. 결합은 로그 면적에 선형인 탐지력 이동 하나로만 넣었다.
- 격자는 100 m 하나다. 굵은 격자는 다시 시뮬레이션하지 않았고, C1(객체 크기 대 칸 크기)로 같은 방향을 대신 봤다. 굵은 칸에서 점수를 평균하는 효과는 C1 에 없다.
- σ ≥ 2.5 에서는 절단(50 m²~10 km²)과 겹침 때문에 객체 AUC 가 σ 에 따라 움직인다 (β = −1: 0.70 → 0.66, β = +1: 0.70 → 0.75). 작은 객체가 큰 이웃 객체의 μ 를 물려받기 때문이다.
- 설계 값 일부(σ 상한 3.0, 중앙 면적 5,000 m², μ0 = 0.95)는 M4 창원 결과를 알고 정했다 (절차 §0 에 공개).
- 사상마다 β 가 다른 경우, 사상 효과가 크기 분포와 함께 바뀌는 경우는 시뮬레이션하지 않았다. 그래서 창원의 V1–V2 대비는 재현하지 못했다.
- 창원 기준점은 post-hoc 이다. τ̂ 에 작은 객체의 표본 잡음이 섞여 Δ̂\* 를 줄이는 쪽으로 치우친다. 인과 추정이 아니라 가상 격자 위의 위치 표시다.
- 모든 요약은 복제 200개의 점추정이다. P10 의 표준오차는 최대 0.035 다 (`f50` 의 n = 30·작은 객체 시나리오는 평가 가능 복제가 119~129개라 최대 0.046).

## 리더 판단 필요

1. **논문에 쓸 문장 제안 (방법·결과).**
   - "격자 AUC 는 객체 기여의 가중평균이고, 객체 AUC 와의 차이 중 크기 가중 항은 ρ(w, A)·sd(A)·√(n_S/n_eff − 1) 이다: 가중치 집중 × 객체 기여 이질성 × 크기–기여 상관."
   - "로그정규 크기(σ)와 로그 면적에 선형인 탐지력(β)에서 차이는 Δ\* = Φ((μ0 + βσ)/D) − Φ(μ0/D) 로 근사된다. 가상 자료 115개 시나리오에서 |Δ\*| ≥ 0.15 이면 차이가 0.1 이상이었고 β = 0 이면 차이가 없었다."
   - 그림 후보: `gap_map_redrawn.png` (σ × β 지도). 창원 기준점은 부록 표.
2. **`rep_point` 의 위치.** M4 에서 `rep_point` 는 격자 AUC 를 객체 AUC 에 가깝게 했다. 이 시연에서도 크기 가중은 없앴지만, 큰 객체가 많은 경관에서는 객체 안 항이 생긴다 (S3 틀림). 논문에서 "편향 없는 대안"으로 쓰지 말 것을 제안한다.
3. **V1–V2 대비의 설명.** 무작위 사상 효과(υ = 0.5)로는 합동과 사상 중앙값이 벌어지지 않았다. 창원의 대비는 "가중치를 거의 다 가진 한 사상만 강한 음의 결합"이라는 사상 특이적 구성에서 나온다. M2·M7 의 서술에서 이 점을 사상 단위 결과로 다룰 것을 제안한다.
4. **추가 시뮬레이션 여부.** 사상별로 다른 β, 가장자리 희석(객체 안 항), 굵은 격자 점수 평균을 넣은 확장은 이번 절차에 없다. 필요하면 새 절차로 고정한 뒤 한다.
