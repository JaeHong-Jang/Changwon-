## 1. 가상 경관과 인벤토리

### 1.1 격자와 배경 점수

- 격자: 100 m 칸 200 × 200 = 40,000칸 (400 km²). EPSG:5179, 좌하단 (1,000,000, 1,700,000). 칸 면적 10⁴ m².
- 배경 점수 z: 칸마다 독립 N(0, 1) 을 `scipy.ndimage.gaussian_filter(sigma=2 칸, mode="wrap")` 로 평활한 뒤,
  그 복제의 표본 평균 0·표준편차 1 로 표준화한다 (공간 자기상관이 있는 지수 점수의 대용).

### 1.2 객체 크기

객체(가상 침수 폴리곤) k 의 면적 a_k 를 다음 중 하나에서 뽑는다. 모두 [50 m², 10 km²] 로 절단한다 (범위 밖이면 다시 뽑는다).

| 분포 | 정의 | 표준화 로그 면적 ζ_k |
|---|---|---|
| `lognormal(m, σ)` | ln a ~ N(ln m, σ²), 중앙 면적 m | (ln a − ln m) / σ |
| `pareto(m, α)` | a = x_m U^(−1/α), U ~ U(0,1), x_m = m · 2^(−1/α) (중앙 면적 m) | α ln(a / x_m) − 1 |

ζ_k 는 생성 분포에서 평균 0·표준편차 1 이다 (절단 전).

### 1.3 모양과 배치

- 타원. 종횡비 r ~ U(1, 3), 방향 U[0°, 180°). 반축 √(a r / π), √(a / (r π)).
  32꼭짓점 다각형(`buffer(quad_segs=8)`)으로 만든 뒤 넓이가 정확히 a 가 되게 배율을 맞춘다.
- 중심은 균등분포에서 뽑되, 장반축 반지름의 원이 영역 안에 들도록 한다 (잘리지 않는다). 객체끼리 겹칠 수 있다.

### 1.4 사상

- 사상 수 E. 사상별 객체 수:
  - `equal`: 모든 사상 n̄ 개.
  - `skewed`: 사상 배율 m_e ~ LogNormal(0, 1.5), n_e = max(1, round(E n̄ m_e / Σ m)).
- 객체 번호는 시나리오 안에서 유일하다.

### 1.5 탐지력과 점수

- 객체 탐지력 μ_k = μ0 + β ζ_k + τ ε_k + υ η_e(k). ε_k, η_e ~ 독립 N(0, 1). τ = 0.5 고정.
  - β: **크기–탐지 결합** (로그 면적 1 표준편차당 탐지력 변화). β < 0 이면 큰 객체일수록 점수가 낮다 (창원 L1 의 농업 대형 폴리곤과 같은 방향).
  - υ: 사상 효과의 표준편차.
- 점수 s_i = z_i + μ_{k(i)}. k(i) 는 칸 i 와 겹침 면적이 가장 큰 객체다 (동점이면 번호가 작은 객체). 어떤 객체와도 겹치지 않은 칸은 s_i = z_i.
- 뜻: 객체 k 에 닿은 칸의 점수가 배경보다 μ_k 만큼 높다. 배경과 독립일 때 칸 하나의 기대 객체 값은 Φ(μ_k / √2) 다 (§5.3).

### 1.6 난수

복제 j 의 난수 생성기 = `numpy.random.default_rng([20260927, 시나리오 번호, j])`. 복제 수 **R = 200**.

## 3. 라벨 규칙과 평가 단위

- 100 m 에서 M4 의 8개 규칙(`src/data/label_rules.py`: `any`, `f01`, `f10`, `f25`, `f50`, `center`, `rep_point`, `soft`)을 그대로 쓴다. 참조 규칙 `f10`.
  B 묶음은 `f10` 만 쓴다.
- **합동 라벨:** 시나리오의 모든 객체(모든 사상)의 합집합. 묶음 A·C·D 는 E = 1 이라 사상 라벨과 같다.
- **사상 라벨 (B):** 사상마다 그 사상 객체의 합집합.
- 격자 AUC 의 음성 = 나머지 모든 칸 (q = 1 − p, M4 §5). 객체 AUC 의 배경 = 시나리오의 어떤 객체와도 닿지 않은 칸 (M4 와 같은 비접촉 배경).

## 4. 측정 (복제 × 규칙마다)

- 격자 AUC A (`weighted_auc`), 상위 20% 포착 (`capture_curve`, 이진 규칙 p 1표·`soft` 는 침수 면적 1표).
- 객체 AUC Ã, 객체 포착 (`curves._object_capture`, 폴리곤별 겹침 면적 중 상위 20% 칸에 든 몫의 평균). 규칙과 무관하다.
- 분해 (`decomposition.object_terms`·`decompose`): 차이 A − Ã = 크기 가중 + 객체 안 + 소실. n_eff, 생존 객체 수 n_S, 유한한 Ã 객체 수 n_K.
- 가중치 집중: 상위 10% 객체 몫 = 가중치가 큰 순서로 ⌈0.1 × 객체 수⌉ 개의 w_k 합 (객체 수 = 소실 포함 전체).
  합동 라벨에서 사상별 가중치 몫의 최댓값 (B).
- 공분산 형태 (§5.2): S 위 정규화 가중치 w̃, n_eff,S, sd_S(A_k) (모표준편차), ρ_S(w̃, A_k), 그리고 크기 가중 항과의 차이.
- 소실 비율 = 1 − n_S / n_K.
- 게이트 (사전 게이트, 낮추지 않는다):
  - 격자 게이트: A ≥ 0.70 이고 포착 ≥ 0.50.
  - 객체 게이트: Ã ≥ 0.70 이고 객체 포착 ≥ 0.50.
  - **단위 뒤집힘:** 격자 게이트 ≠ 객체 게이트. **AUC 단위 뒤집힘:** (A ≥ 0.70) ≠ (Ã ≥ 0.70).
  - **규칙 뒤집힘:** 규칙 r 의 격자 게이트 ≠ `f10` 의 격자 게이트 (같은 복제).
  - **사상 집계 뒤집힘 (B):** V1 = 합동 라벨 격자 게이트, V2 = 양성 칸 ≥ 5 인 사상들의 격자 AUC·포착 중앙값 게이트 (M4 §7 의 V1·V2). V1 ≠ V2.
- 최소 표본: 양성 칸 < 5 인 행, 유한한 Ã 가 3개 미만인 행은 표에 남기되 요약에서 뺀다 (M4 와 같음).
- 독립 검산: 각 시나리오 복제 0 의 모든 규칙에서 A 를 `sklearn.metrics.roc_auc_score`(M4 `sklearn_auc`)로 다시 계산한다.

**시나리오 요약 (시나리오 × 규칙):** 평가 가능 복제에서 차이 중앙값, P10 = P(|A − Ã| ≥ 0.1), P(차이 ≥ 0.1), P(차이 ≤ −0.1),
세 항·n_eff·n_S·상위 10% 몫·소실 비율의 중앙값, 뒤집힘 비율. **분류:** P10 ≥ 0.5 → `벌어짐`, 0.1 ≤ P10 < 0.5 → `가끔`, P10 < 0.1 → `없음`.

## 5. 해석 결과 (계산 전 유도)

### 5.1 분해 (M4 §6)

A = Σ_k w_k A_k, w_k = W_k / Σ W. A − Ã = [A − mean_S A_k] + [mean_S A_k − mean_S Ã_k] + [mean_S Ã_k − mean_K Ã_k].
S = {W_k > 0 이고 Ã_k 유한} (M4 §9), K = {Ã_k 유한}.

### 5.2 크기 가중 항의 공분산 형태 (새 유도)

S 위 정규화 가중치 w̃_k = W_k / Σ_{S} W, n_S = |S|, n_eff,S = 1 / Σ_S w̃_k², Ā = mean_S A_k 라 하자.
할당되지 않은 양성 질량이 0 이고 W > 0 인 객체가 모두 S 에 있으면 Σ_S w̃_k = 1 이고 A = Σ_S w̃_k A_k 이므로

**크기 가중 항 = Σ_S (w̃_k − 1/n_S)(A_k − Ā) = n_S Cov_S(w̃, A) = ρ_S(w̃, A) · sd_S(A) · √(n_S / n_eff,S − 1)**

(모표준편차·모공분산. n_S sd(w̃) = √(n_S Σ w̃² − 1) = √(n_S / n_eff,S − 1).) 따라서

- |크기 가중 항| ≤ sd_S(A) √(n_S / n_eff,S − 1). 차이는 **가중치 집중 × 객체 기여 이질성 × 크기–기여 상관** 세 인수의 곱이다.
- 크기와 무관한 기여(A_k 가 가중치와 독립, 분산 s²)이면 가중치를 고정할 때 기대값 0, 표준편차 s √(1/n_eff,S − 1/n_S). 체계적 차이는 없지만 n_eff 가 작으면 우연 차이가 커진다.
- 소실 항 = (1 − n_S/n_K) (mean_S Ã − mean_{K∖S} Ã). 소실된 객체와 생존 객체의 객체 값이 다를 때만 0 이 아니다.

수치 확인: 조건(할당 안 된 질량 0, n_survive_no_At = 0)을 만족하는 모든 행에서 좌변과 우변의 절대차 ≤ 1e-9.

### 5.3 로그정규 크기에서 모집단 차이 (지수 기울임)

ζ ~ N(0, 1), 가중치 ∝ 면적 ∝ e^{σζ} 이면 가중치로 잰 ζ 의 분포는 N(σ, 1) 이다. 칸 점수 z + μ 와 독립 배경 z' ~ N(0,1) 에서
P(z + μ > z') = Φ(μ/√2) 이고, E[Φ((m + cZ)/√2)] = Φ(m / √(2 + c²)) 이므로 (μ_k = μ0 + βζ_k + τε_k)

- 객체 AUC → Φ(μ0 / D), 면적가중 격자 AUC → Φ((μ0 + βσ) / D), D = √(2 + β² + τ²),
- **Δ\*(σ, β) = Φ((μ0 + βσ)/D) − Φ(μ0/D).**

성질: β = 0 또는 σ = 0 이면 Δ\* = 0 (둘이 함께 있어야 체계적 차이가 난다). sign(Δ\*) = sign(β). 가정: 가중치 ∝ 면적(`soft` 에 해당), 절단 없음, n → ∞.
`f10` 은 칸 수로 셈해 작은 객체를 1칸으로 올리거나(바닥) 지우므로(소실) 가중치가 면적보다 덜 집중된다. 그래서 `f10` 의 크기 가중 항은 Δ\* 보다 작을 것으로 본다.
σ ≥ 2.5 에서는 기울인 분포의 중심(e^{σ²} 배 큰 객체)이 절단 상한·표본 최댓값을 넘어 Δ\* 가 실현 차이를 과대평가한다.

μ0 = 0.95, τ = 0.5 의 Δ\* (계산 전 공식 값):

| β \ σ | 0.5 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---:|---:|---:|---:|---:|---:|
| −1 | −0.102 | −0.212 | −0.321 | −0.421 | −0.506 | −0.573 |
| −0.5 | −0.055 | −0.114 | −0.176 | −0.239 | −0.301 | −0.362 |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 0.5 | 0.050 | 0.094 | 0.133 | 0.165 | 0.192 | 0.213 |
| 1 | 0.089 | 0.159 | 0.212 | 0.248 | 0.271 | 0.285 |

D 묶음 (σ = 1.5): μ0 = 0.55 에서 β = −1, −0.5, 0.5, 1 순으로 −0.321, −0.186, 0.158, 0.252. μ0 = 1.45 에서 −0.300, −0.149, 0.098, 0.160.
로그정규 가중치 집중 (면적 가중): 상위 10% 몫 = 1 − Φ(1.2816 − σ) → σ = 0.5, 1, 1.5, 2 에서 0.217, 0.389, 0.586, 0.764. n_eff / n → e^{−σ²}.

## 6. 예측과 판정 규칙

### 6.1 주 예측 (판정에 쓴다)

- **P1 (항등식, 구현 검사):** 모든 행에서 |Σ w_k A_k − A| ≤ 1e-9, 복제 0 의 sklearn 경로 ≤ 1e-9, §5.2 공분산 형태 ≤ 1e-9.
  실패하면 판정하지 않고 구현 오류로 멈춘다.
- **P2 (결합이 없으면 체계적 차이가 없다):** 묶음 A·C·D 의 β = 0 인 모든 시나리오에서, `f10`·`soft` 모두
  차이 중앙값의 절댓값 < 0.03 이거나, 중앙값의 95% 순서통계량 구간이 0 을 포함한다
  (평가 가능 복제 수 R′ 에서 1부터 센 순위 ⌊R′/2 − 0.98√R′⌋ 와 ⌈1 + R′/2 + 0.98√R′⌉ 의 값. R′ = 200 이면 86번째·115번째).
  n = 30 처럼 우연 차이가 큰 시나리오가 잡음만으로 틀리지 않게 하려는 조건이다.
- **P3 (분산과 결합이 함께 있으면 벌어진다, `soft`):** 묶음 A (n = 200, σ ≤ 2.0) 와 D 에서
  - |Δ\*| ≥ 0.15 인 시나리오는 모두 `벌어짐` 이고 차이 중앙값의 부호가 β 의 부호와 같다.
  - |Δ\*| < 0.06 인 시나리오는 모두 `벌어짐` 이 아니다.
- **P3′ (같은 예측, `f10`, 칸 수 가중의 약화를 감안):** 같은 시나리오에서
  - |Δ\*| ≥ 0.15 인 시나리오는 모두 차이 중앙값의 부호가 β 의 부호와 같고, 그중 |Δ\*| ≥ 0.20 인 시나리오는 모두 `벌어짐` 이다.
  - |Δ\*| < 0.06 인 시나리오는 모두 `벌어짐` 이 아니다.

**판정 (C-c 분해의 일반성):**
1. P2·P3·P3′ 가 모두 맞으면 → "일반성 지지: 격자 AUC 와 객체 AUC 의 0.1 이상 차이는 크기 분산과 크기–탐지 결합이 함께 있을 때 생기며, 그 방향과 크기가 §5.3 공식으로 예측된다. 창원 고유의 성질이 아니다."
2. P2·P3·P3′ 중 일부만 맞으면 → "부분 지지". 틀린 예측과 시나리오를 나열한다.
3. 셋 다 틀리면 → "폐기: 가상 자료에서 분해의 차이가 예측대로 나타나지 않는다."

### 6.2 보조 예측 (판정에 쓰지 않는다, 맞음/틀림을 그대로 보고)

- **S1 우연 차이:** β = 0 시나리오에서 P10 ≥ 0.1 은 `f10` n_eff 중앙값 < 20 인 시나리오에서만 나온다.
- **S2 소실:** 묶음 A·C1 의 `f10` 에서, β ≠ 0 이고 소실 비율 중앙값 ≥ 0.2 이면 소실 항 중앙값의 부호 = β 의 부호.
  β = 0 이면 |소실 항 중앙값| < 0.02 이거나 P2 와 같은 순서통계량 구간이 0 을 포함한다.
- **S3 대표점 규칙:** 묶음 A·C·D 의 n = 200 시나리오에서 `rep_point` 의 |차이 중앙값| < 0.05.
- **S4 집중:** `soft`, 묶음 A n = 200, σ ≤ 1.5 에서 상위 10% 몫 중앙값이 §5.3 의 로그정규 값과 ±0.10 안.
- **S5 사상 집중 (B):** E = 4 `skewed` 의 사상별 최대 가중치 몫 중앙값 ≥ 0.5, E = 4 `equal` 은 < 0.5.
- **S6 창원 기준점 (§7):** 기준점 전체에서 Δ̂\* 와 관측 `f10` 차이의 Spearman 상관 ≥ 0.5. L1 `HOLDOUT_ALL` 의 Δ̂\* ≤ −0.1.

### 6.3 게이트 판정이 바뀌는 조건 (기술)

- AUC 단위 뒤집힘은 정의상 (A − 0.70)(Ã − 0.70) < 0, 곧 차이가 Ã 와 0.70 의 거리보다 크고 방향이 반대일 때다.
  시나리오별 뒤집힘 비율을 차이 중앙값·객체 AUC 중앙값과 함께 싣고, 모든 복제를 (Ã − 0.70) 구간 × 차이 구간으로 묶은 뒤집힘 비율 표를 싣는다
  (구간: Ã − 0.70 ∈ (−∞, −0.1), [−0.1, −0.05), [−0.05, 0), [0, 0.05), [0.05, 0.1), [0.1, ∞); 차이 ∈ (−∞, −0.2), [−0.2, −0.1), [−0.1, 0), [0, 0.1), [0.1, 0.2), [0.2, ∞)).
- 규칙 뒤집힘 비율 (규칙 × 시나리오), 사상 집계 뒤집힘 비율 (B).

결과를 본 뒤 생성 규칙·시나리오·예측·임계를 바꾸면 `post-hoc` 으로 표기하고 이 절차의 결과를 함께 싣는다.

## 7. 창원 기준점 (post-hoc, 보조)

M4 공식 run 의 `object_contrib.parquet`·`decomposition.csv` 에서 (시험 사상, 점수) 마다, 규칙 `f10`·`soft`, 100 m:

- 대상: 유한한 Ã_k 가 20개 이상인 (시험 사상, 점수).
- σ̂ = sd(ln a_k) (모표준편차), ζ̂_k = (ln a_k − mean) / σ̂.
- μ̂_k = √2 Φ⁻¹(clip(Ã_k, 0.005, 0.995)). OLS μ̂_k = μ̂0 + β̂ ζ̂_k + 잔차, τ̂ = 잔차 모표준편차.
- Δ̂\* = §5.3 공식에 (σ̂, β̂, μ̂0, τ̂) 를 넣은 값. 관측 차이·세 항·n_eff 와 나란히 싣는다.
- §5.2 공분산 형태를 실제 자료에서 확인한다 (조건을 만족하는 행, 절대차 ≤ 1e-9).
- τ̂ 에는 작은 객체의 표본 잡음이 섞여 Δ̂\* 를 0 쪽으로 줄인다. 이 기준점은 인과 추정이 아니라 가상 격자 위의 위치 표시다.
