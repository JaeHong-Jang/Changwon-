# M4 절차 — 라벨 규칙 × 격자 크기 민감도 (계산 전 고정)

> 과제 정의: `docs/CLOUD_TASKS.md` M4. 규칙: `AGENTS.md` §2·§6·§8.
> 이 문서는 **라벨 규칙·격자 크기·점수·지표·판정 규칙을 계산 전에 고정**하려고 커밋한다.
> 이 커밋 전에는 M4 설정(규칙·크기)으로 AUC·포착·생존율을 하나도 계산하지 않았다.

## 0. 지위와 이미 본 것

- **post-hoc.** 2022~2024 홀드아웃 결과를 이미 봤다. M4 는 홀드아웃을 채점에만 쓰지만 사전등록 검증이 아니다.
- 이 절차를 쓰기 전에 본 결과:
  - 공식 홀드아웃: L1 격자 AUC 0.436, 포착 0.073 (100 m·10% 규칙). 같은 사상의 덩어리 0.603·객체 0.712·면적 0.408.
  - 라벨 감사 (`label_audit_*_1b8106ba`): 100 m 에서 10% 격자 규칙·자기 10%·대표점 격자 규칙의 폴리곤 생존율.
  - M1 (`m1_20260926T160821Z_a181f6c`): 100 m·10% 규칙의 사상별 격자·객체 AUC 전부.
- 라벨 없이 본 것: 굵은 격자 칸 수 (아래 §3 표). 흔적과 겹쳐 본 굵은 격자 값은 없다.

## 1. 시험 사상

M1 과 같다 (`docs/q1/M1_protocol.md` §1).

- 개발: `event_date` 연도가 2006, 2012, 2014, 2016, 2019, 2025 인 개발 흔적 (날짜 없는 흔적 제외).
- 홀드아웃: `storm_id` 별 4사상 (2022-09, 2023-08, 2024-07, 2024-09).
- **합동 홀드아웃 `HOLDOUT_ALL`:** 홀드아웃 4사상 흔적 전부를 한 라벨 집합으로 쓴다. 공식 사전 게이트(0.436/0.073)와 같은 단위다.
- 한 사상 안의 라벨은 그 사상 폴리곤의 합집합으로 만든다 (겹친 폴리곤 면적은 한 번만 센다).

## 2. 라벨 규칙 (8개)

격자 칸 i 의 **침수 비율** f_i = (칸 안 사상 폴리곤 합집합 면적) / (칸 면적). 규칙은 칸마다 양성 질량 p_i ∈ [0, 1] 을 준다.
이진 규칙은 p_i ∈ {0, 1}, 음성 질량 q_i = 1 − p_i.

| 이름 | 정의 | 비고 |
|---|---|---|
| `any` | f_i > 0 | 교집합 > 0. `rasterize(all_touched=True)` 에 해당 |
| `f01` | f_i > 0.01 | |
| `f10` | f_i > 0.10 | **참조 규칙.** 현행 `label_grid`·공식 게이트와 같다 |
| `f25` | f_i > 0.25 | |
| `f50` | f_i > 0.50 | 다수결 |
| `center` | 칸 중심점이 사상 폴리곤 안 | `rasterize` 기본 규칙. 굵은 칸의 중심점은 §3 정의 |
| `rep_point` | 폴리곤 대표점(`representative_point`)이 든 칸 | 추가 규칙. `label_audit` 의 `rule_point_cell` 과 같다. 격자 안에 대표점이 있는 폴리곤마다 양성 1칸을 보장 |
| `soft` | p_i = f_i (연성) | 면적가중 연성 라벨. 침수 1 m² 마다 1표 |

- 임계 비교는 `label_grid` 와 같이 초과(>)다.
- `rep_point` 의 대표점이 100 m 칸 경계에 걸리면 번호가 작은 칸을 쓴다.

## 3. 격자 크기와 집계

크기 s ∈ {100, 200, 500, 1000} m. 100 m 미만은 DEM 90 m 한계로 뺀다.

- **굵은 칸:** EPSG:5179 절대좌표 격자 (x, y 가 s 의 배수인 선에 정렬). 100 m 칸은 좌하단 좌표의 `floor(·/s)` 로 굵은 칸에 속한다.
- **분석 영역은 모든 크기에서 같다:** 굵은 칸의 기하 = 그 안의 분석 격자(100 m 칸) 합집합. 경계의 부분 칸도 그대로 둔다.
  - 칸 면적 = 구성 100 m 칸 수 × 10⁴ m². 칸 중심점 = 구성 100 m 칸 중심점의 평균 (같은 크기 정사각형 합집합의 무게중심).
  - 침수 합집합 면적 = 구성 100 m 칸 합집합 면적의 합 (100 m 칸끼리 겹치지 않으므로 정확하다).
  - 폴리곤-칸 겹침 면적 a_ki = 구성 100 m 칸과의 겹침 면적의 합.

| 크기 | 칸 수 | 완전 칸 | 구성 칸 수 중앙값 |
|---|---:|---:|---:|
| 100 m | 75,400 | 75,400 | 1 |
| 200 m | 19,483 | 18,244 | 4 |
| 500 m | 3,393 | 2,663 | 25 |
| 1000 m | 942 | 584 | 100 |

- **점수 집계:** 모든 점수는 100 m 에서 한 번 계산하고, 굵은 칸 점수는 구성 100 m 칸 점수의 **산술평균**(결측 제외)이다.
  구성 칸이 모두 결측이면 결측. 특징을 집계해 지수를 다시 만들거나 모형을 굵은 격자에서 다시 적합하지 않는다.
  이유: 같은 동결 점수를 평가 단위만 바꿔 채점해야 라벨 규칙·크기의 효과만 분리된다.

## 5. 지표 (설정 = 규칙 × 크기, 32개. 사상 11개 = 개발 6 + 홀드아웃 4 + `HOLDOUT_ALL`)

모든 지표는 점추정이다 (재표본 구간 없음. 사상 수준 불확실성은 M2).

- **격자 AUC (게이트 단위):** 양성 질량 p, 음성 질량 q = 1 − p 인 가중 Mann–Whitney.
  A = Σ_i Σ_j p_i q_j H(s_i − s_j) / (Σ p_i · Σ q_j), H(x) = 1 (x > 0), ½ (x = 0), 0 (x < 0). 점수 결측 칸은 뺀다.
  이진 규칙에서 이것은 `layers.roc_auc` (양성 대 나머지 전 격자)와 같다.
- **상위 20% 포착:** 점수 내림차순으로 칸을 쌓아 **점수가 있는 칸 면적**의 20% 까지 (마지막 칸은 비율로) 고른다.
  포착 = 고른 칸의 양성 질량 합 / 전체 양성 질량 합. 이진 규칙은 양성 칸 1표, `soft` 는 침수 면적 1표 (`V.capture_curve`).
  100 m 에서 점수 결측이 없으면 `top_share_lift` (M1·공식 게이트)와 같다.
- **객체 AUC (폴리곤 1표):** M1·`evaluate` 와 같은 정의를 크기마다 적용한다. 폴리곤 k 의 값 Ã_k = Σ_i a_ki G(s_i) / Σ_i a_ki,
  G = 비접촉 배경 칸(개발·홀드아웃 어느 흔적과도 닿지 않은 칸) 점수의 중간 누적분포. 객체 AUC = 유한한 Ã_k 의 평균.
  라벨 규칙과 무관하고 크기에만 달라진다.
- **표본:** 양성 칸 수 (`soft` 는 f_i > 0 인 칸 수), 양성 칸 덩어리 수 (`spatial_clusters`, 반경 1.5 s).
- **객체 생존:** 폴리곤이 겹친(a_ki > 0) 칸 중 양성 칸(p_i > 0)이 하나라도 있으면 생존. 라벨은 그 폴리곤의 사상(개발 연도·홀드아웃 호우) 합집합 라벨.
  분석 영역과 겹치지 않는 폴리곤은 분모에서 빼고 수를 따로 적는다. `soft`·`any` 는 정의상 생존율 1 이다 (검산).
  - 면적 구간: `label_audit.AREA_BINS` (<500, 500–1k, 1k–5k, 5k–20k, ≥20k m², 폴리곤 전체 면적).
  - 토지이용 구간: 홀드아웃의 `land_use` (`label_audit._land_class`: 도심·농업·미상). 개발 흔적에는 속성이 없다.

최소 표본: 사상×설정에서 양성 칸 < 5 이면 격자 지표는 표에 싣되 중앙값·판정에서 뺀다. 객체 지표는 폴리곤 < 3 이면 뺀다 (M1 과 같음).

## 6. 해석적 분해: 격자 AUC = 객체 기여의 가중평균

**유도.** F(s) = Σ_j q_j H(s − s_j) / Σ_j q_j (음성 질량의 중간 누적분포)라 하면 A = Σ_i p_i F(s_i) / Σ_i p_i 이다.
p_i > 0 인 칸 i 를 겹친 폴리곤들에 면적 비율 π_ki = a_ki / Σ_k' a_k'i 로 나눈다 (Σ_k π_ki = 1). 폴리곤 k 에 대해

- 가중치 W_k = Σ_i p_i π_ki (폴리곤이 만든 유효 양성 칸 수, `soft` 에서는 겹침 면적 / 칸 면적)
- 객체 기여 A_k = Σ_i p_i π_ki F(s_i) / W_k (W_k > 0 일 때: 그 폴리곤 양성 칸들의 게이트 배경 대비 AUC)

라 두면 Σ_k W_k A_k = Σ_i p_i F(s_i) Σ_k π_ki = Σ_i p_i F(s_i), Σ_k W_k = Σ_i p_i 이므로

**A = Σ_k w_k A_k, w_k = W_k / Σ_k' W_k'.**

격자 AUC 는 객체 기여의 가중평균이고, 가중치는 폴리곤이 만든 양성 칸 질량이다. W_k = 0 인 폴리곤(소실)은 가중치 0 이다.
큰 폴리곤·큰 사상이 격자 AUC 를 정한다. `soft` 에서는 w_k 가 폴리곤의 (중복 제거) 침수 면적에 비례한다.
분해는 점수 결측이 없는 칸 기준이다 (결측 칸의 p 는 A 에서도, W 에서도 빠진다).

**객체 AUC 와의 차이 (정확한 세 항 분해).** S = {k : W_k > 0} (생존 객체), K = 유한한 Ã_k 가 있는 객체라 하면

A − Ã = [A − mean_{k∈S} A_k] + [mean_{k∈S} A_k − mean_{k∈S} Ã_k] + [mean_{k∈S} Ã_k − mean_{k∈K} Ã_k]

- 1항 **크기 가중 효과:** 생존 객체를 같은 무게로 볼 때와의 차이.
- 2항 **객체 안 효과:** 양성 칸만·게이트 배경(부분 침수 칸도 음성) 대 겹친 모든 칸·비접촉 배경.
- 3항 **소실 효과:** 소실 객체를 빼서 생기는 차이.
- 보조: 유효 객체 수 n_eff = 1 / Σ w_k² (Kish), 면적 구간·호우별 가중치 몫 Σ w_k.

**수치 확인.** 모든 (사상, 설정, 점수)에서 A 를 독립 경로(`sklearn.metrics.roc_auc_score`, 칸을 양성 p·음성 q 가중 표본 두 개로 복제)로 계산하고
Σ w_k A_k 와 비교한다. **최대 절대차 ≤ 1e-9** 가 아니면 분해 구현 오류로 보고 실행을 멈춘다.

## 7. 판정 규칙

참조 설정 R = (`f10`, 100 m). 게이트 여유 m = min(격자 AUC − 0.70, 포착 − 0.50). 통과 ⇔ m ≥ 0 (사전 게이트, 낮추지 않는다).

- **V1 (합동 홀드아웃 게이트):** `HOLDOUT_ALL` 에서 점수별 m.
- **V2 (사상별 중앙값 게이트):** E\* = 그 설정에서 10개 점수가 모두 있고 양성 칸 ≥ 5 인 시험 사상 (개발·홀드아웃, `HOLDOUT_ALL` 제외).
  E\* 에서 격자 AUC 중앙값과 포착 중앙값으로 m 을 만든다. E\* 는 설정마다 다를 수 있다 (예: `any` 에서 2022-09·2024-07 이 들어올 수 있다). 사상 목록을 함께 적는다.
- **뒤집힘:** 설정 c 의 통과 여부가 R 과 다름. **실질 뒤집힘:** 뒤집힘이고 |m(R)| ≥ 0.02 이며 |m(c)| ≥ 0.02 (경계 근처의 흔들림 제외).
- **순위:** V1 격자 AUC 와 V2 격자 AUC 중앙값으로 10개 점수를 줄 세운다. R 대비 Kendall τ_b, L1 의 순위.
  두 점수 순서의 **실질 역전:** 두 설정에서 격자 AUC 차이가 부호가 반대이고 둘 다 절대값 ≥ 0.02.

**주 판정 (C-c, 대상 = 동결 지수 L1).** 관행 설정 C_conv = {(`any`, 100 m), (`center`, 100 m), (`f50`, 100 m)}
(GIS 래스터화의 표준 선택지: all_touched·중심점·다수결).

1. L1 의 V1 또는 V2 **실질 뒤집힘**이 C_conv 에 하나라도 있으면 → "C-c 지지: 해상도를 그대로 두고 관행 래스터화 규칙만 바꿔도 L1 게이트 판정이 뒤집힌다."
2. 1 이 아니고, 다른 설정(비관행 규칙 또는 굵은 격자)에 L1 실질 뒤집힘이 있으면 → "C-c 부분 지지: 비관행 규칙 또는 격자 크기를 바꿔야 뒤집힌다." 해당 설정을 나열한다.
3. 둘 다 아니면 → "C-c 폐기(라벨 규칙·격자 크기 축): L1 의 사전 게이트 판정은 32 설정에서 실질적으로 뒤집히지 않는다."
   이 경우 격자 대 객체 단위 차이는 별도 결과로만 남긴다.

**보조 (판정에 쓰지 않는다, 그대로 보고):**
- 10개 점수 모두의 V1·V2 뒤집힘·실질 뒤집힘 표 (규칙만 바뀐 설정 / 크기만 바뀐 설정 / 둘 다로 나눔).
- 점수별 격자 AUC 범위(최대 − 최소, 32 설정).
- L1 과 다른 점수(특히 `rf_F1_wf`, `slope_neg`)의 순서 실질 역전.
- M1 주 판정(경사 대 RF, E\* 격자 AUC 중앙값, 0.02 규칙)을 각 설정에서 다시 적용한 결과. M1 판정은 바꾸지 않는다.
- 객체 크기·토지이용 구간별 생존율 (규칙 × 크기 × 역할).
- 분해 세 항과 n_eff, 가중치 몫.

결과를 본 뒤 규칙·임계·설정 정의를 바꾸면 `post-hoc` 으로 표기하고 이 규칙의 결과를 함께 싣는다.
