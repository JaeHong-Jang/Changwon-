# 정보공개청구 문안

## 신청 방법
- **정부24** (https://www.gov.kr) → 정보공개청구 → 온라인 신청
- 누구나 무료로 신청 가능
- **처리기간: 10영업일 이내** (공공기관의 정보공개에 관한 법률)

## 청구 대상 기관
**경상남도 창원특례시 하수도사업소**

## 청구 제목
창원시 하수도 민원 접수 현황 데이터 공개 요청 (학술 연구 목적)

## 청구 내용 (복사해서 붙여넣기)

```
안녕하세요.

2026년 창원시 AI·데이터 활용 공모전 참가를 위한 학술 분석 목적으로
아래 데이터의 공개를 요청드립니다.

[요청 데이터 1] 최근 3년간(2023~2025년) 하수도 관련 민원 접수 현황
   - 접수일시
   - 민원 유형 (악취, 역류, 배수불량, 맨홀파손 등)
   - 민원 발생 위치 (동 단위 또는 도로명 주소)
   - 처리 결과 (처리완료, 진행중 등)
   - 민원 내용 요약 (개인정보 제외)

[요청 데이터 2] 하수관로 노후화 현황 (보유 시)
   - 관로별 설치연도 및 경과연수
   - 관로 재질, 관경(mm)
   - 위치 (동 단위 이상, 좌표 제공 가능 시)
   - 최근 점검·보수 이력 (보유 시)

[요청 데이터 3] 침수흔적도 (보유 시)
   - 최근 10년(2015~2025년) 침수 발생 구역 도형자료 (SHP 또는 GeoJSON)
   - 침수 일자, 침수 원인(하천범람/내수침수), 침수심(보유 시)
   ※ 국토연구원 선행연구(최유라·한우석, 2024)에서 창원시로부터 2011~2020 침수흔적도를
      제공받아 분석한 사례가 있어, 동일 자료의 최신본을 요청드립니다.

※ 데이터 형식: CSV 또는 Excel 파일 (도형자료는 SHP/GeoJSON)

[활용 목적]
- 2026년 창원시 AI·데이터 활용 공모전 출품작 분석 자료
- 폭우 시 침수 취약지역 + 하수도 역류 위험 + 취약계층을 통합 분석하여 우선 점검·대응 지역을 선정하는 연구
- 학술 연구 목적으로만 활용하며, 개인정보는 포함하지 않아도 됩니다

[참고]
- 개인정보(신고자 성명, 연락처 등)는 제외하고 제공해 주셔도 됩니다.
- 위치 정보는 동 단위까지만 제공해 주셔도 분석에 충분합니다.

감사합니다.
```

## 예상 일정
- **8/18 (오늘)**: 청구 접수
- **~9/1**: 회신 수령 (10영업일)
- **9/1~9/30**: 데이터 분석 및 보고서 작성

## 참고
- 거부될 경우: 동 단위 집계 데이터(월별·동별 민원 건수)로 범위를 좁혀서 재청구
- 대안 데이터: 국민신문고 민원빅데이터(bigdata.epeople.go.kr)에서 지역별 민원 통계 활용
