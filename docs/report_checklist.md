# 보고서 제출 체크리스트 (G013·G014 검증 기준)

> 리서치에서 확인한 심사 포인트·감점 요인을 체크 항목으로 바꾼 것. **전 항목 ✓ 없이는 G013 완료 불가.**

## 형식 (1차 실무진 서류평가 대응)
- [ ] 총 페이지 10매 이상 20매 이하 (`pdfinfo` 로 확인, 20매 초과분은 미평가)
- [ ] 2026 공식 서식 목차 순서: 분석 개요 → 분석 결과 상세(데이터·툴·알고리즘·스토리보드) → 결과 해석 및 시사점 → 활용방안·기대효과 → 데이터·문헌 출처
- [ ] 참가신청서(붙임1) 별도 작성·개인정보 동의 포함
- [ ] 팀원 전원 이름·소속 일치 (재학증명서와 대조)

## 중복·차별화 (1차 "아이디어 중복 여부")
- [ ] 1장 서두에 **2022 창원 우수상 "침수예측모델(LGBM)" 대비 차별화 비교표** 배치
- [ ] "선행연구(최유라·한우석 2024, 박기용 외 2017)는 도시계획 관점 — 격자 통합지수·취약계층 결합·민원 데이터 활용은 공백" 서술

## 데이터 (데이터 분석·활용 적정성)
- [ ] 데이터 출처 표: 데이터명 · 제공기관 · URL · 기간 · 건수 · 용도 (전 항목)
- [ ] **창원시 데이터포털 또는 창원시 제공 데이터 1건 이상** 눈에 띄게 (강수량·하천수위·배수펌프장)
- [ ] 정보공개청구 데이터는 "창원시 하수도사업소 정보공개 회신(2026.9.x)"으로 출처 기재
- [ ] 전처리 과정(결측·좌표계·격자화) 재현 가능하게 서술 + GitHub 링크
- [ ] 라이선스 주의 데이터(배수구역 SHP 4유형) 파생물 재배포 안 함

## 방법·결과 (창의성 + 적정성)
- [ ] 자체 지수 **"창원 배수인프라 위험지수(CDRI)"** 수식 정의 (R = H × E × V)
- [ ] 국토부 지침(100m 격자·기후노출×민감도·Jenks) + IPCC AR5 이중 근거 명시
- [ ] Layer 1 검증 수치 (사례지 적중 · 민원 위치 포함률)
- [ ] Layer 2 검증 수치 (A: F1/AUC·SHAP / B: Spearman ρ)
- [ ] 가중치 민감도 표 (동일·엔트로피·AHP → TOP 20 순위 상관)
- [ ] 분석 파트 = 전체의 75% 이상 (12매↑) · 지도 6~8장 · 표 4~6개 (지도 중심, 0/1 단조 결과 금지 — 등급·기여도로)
- [ ] **TOP 20 격자 표**: 격자ID · 행정동 · 도로명/랜드마크 · CDRI · 등급 · 기여도(침수/역류/취약 %)

## AI 요소 (장식 금지)
- [ ] LLM 민원 구조화는 **3장 방법론**에 (정확도 표: 수작업 100건 대비 %)
- [ ] 챗봇·시민 안내 없음. 알림 예시는 활용방안 안 **≤1p** (화면 1장 + "특보→알림 N초"), 없어도 보고서 성립
- [ ] 분석 결과 없이 AI 기능 설명이 먼저 나오는 페이지 없음
- [ ] 스토리보드 = 분석 파이프라인 흐름도(데이터→격자→레이어→CDRI→TOP 20)

## 활용방안·기대효과 (관련 부서 심사 대응)
- [ ] 담당 부서 명시: 하수도사업소(3개 하수센터·78억 정비), 재난안전대책본부(폭우 TF)
- [ ] 기존 사업에 끼워 넣는 형태의 **3개월 시범 운영안** (TOP 20 우선 점검)
- [ ] 정량 기대효과 (점검 인력 효율, 민원 초동대응 시간, 예상 민원 감소)
- [ ] 확장성 (타 시군 적용, 폭염 레이어 추가 가능)
- [ ] 창원시 정책 어젠다 연결 (특례시, 기후위기 대응, 도시재생)

## 감점 방지
- [ ] "개선 필요" 같은 추상적 제언 없음 — 전부 "어디에·무엇을·얼마나"
- [ ] 모든 그림·표에 번호·제목·출처
- [ ] 다른 팀원이 리뷰(작성자 ≠ 리뷰어) 후 코멘트 반영 기록
- [ ] 노트북 01~05 Restart & Run All 전부 통과 (재현성)
