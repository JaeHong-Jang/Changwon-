# 작업자용 배경 자료 — 창원 CDRI 논문화 (2026-09-24)

## 연구 한 줄
창원시(약 747 km²)를 SGIS 100m 격자 75,400칸으로 나눠 폭우 우선대응 지수 CDRI 를 만든다.
CDRI = H^w · E^w · V^w · D^w (가중기하평균, 각 요소 [0.05, 1] 재척도, w = 1/4).
- H = Layer 1 침수취약성 = minmax(Z_노출 + Z_민감도). 국토부 「도시 기후변화 재해취약성분석 지침」(2024) 구조
  - Z_노출: 관측소 29곳(2015~2024) 강수 통계 4개(연최대 1h, 30mm 이상 시간수, 상위5 3h·24h)를 IDW 로 보간 → z-score 합
  - Z_민감도: 상대고도(−), 경사(−), TWI(+), 불투수면(+), 하천 근접(+), 복개천 근접(+), 시 침수예상도 L210 100년 침수심(+), 펌프장 1km(+)
- E = 인구·주택 수, V = 65세 이상 비율(집계구), D = 1 − 대피소·방재기관 접근성
- 등급 R1~R5: 침수 발생률 등온회귀(PAV)로 경계 캘리브레이션, 사상 단위 leave-one-event-out
- 우선대응 TOP 20: CDRI 상위 + 300m NMS
- Layer 2(하수 역류)는 관로 자료 비공개로 제외

## 검증 설계 (사전 등록된 게이트)
라벨: 침수흔적 폴리곤이 격자 면적의 10% 초과 겹치면 양성. 음성 = 나머지 전부(흔적도에 음성 기록 없음).
게이트: ROC-AUC ≥ 0.70, 상위 20% 격자 포착률 ≥ 0.50. 불확실성: 150m 연결 덩어리 단위 cluster bootstrap,
"침수 1건 = 1표" AUC 병기, 시 침수예상도와 짝지은 비교. 결과를 본 뒤 재튜닝 금지(하네스 규칙).

## 기존 보고 (2006·2012·2014·2016·2019 행안부 API + 2025 시 회신, 6개 사상)
양성 642칸 = 독립 침수 46건. AUC 0.750 [0.633, 0.863] (격자 1표), 0.704 [0.629, 0.775] (침수 1표),
상위 20% 포착 54.4%. 시 예상도 대비 +0.081 [+0.024, +0.139] (침수 1표). 사상별 AUC 0.37~0.96.
등급: R1~R3 발생률 평탄, 추세 확률 91.9% < 99% 기준.

## 2026-09-24 새로 확인된 사실 (독립 재계산으로 교차검증 완료)
창원시 원본 침수흔적 2022-09 힌남노(5), 2023-08 카눈(3), 2024-07(5), 2024-09(183) 폴리곤 — 지수 확정 후 처음 본 자료.
지수를 동결한 채 채점:
1. Layer 1 AUC 0.436 [0.386, 0.596] (격자 1표), 0.603 [0.544, 0.661] (침수 1표), 상위 20% 포착 7.3% → 게이트 탈락
2. 인구 거주 격자에서 CDRI AUC 0.34, 동결 등급 발생률 역전(R1 1.68% > R3 0.20%), TOP 20 적중 0
3. 강수 노출 축 단독 AUC: 기존 라벨 0.389, 새 라벨 0.147 (무작위 이하). 민감도 축 단독 0.869 / 0.735.
   2024-09 사상의 실제 사상 강우 IDW 도 AUC 0.27 (산지 강우 ↔ 저지대 침수, 지형 교란 의심)
4. 10% 겹침 규칙: 도심 폴리곤 57개 중 52개가 1,000 m² 미만이라 격자 양성이 될 수 없음.
   폴리곤 1표로 채점하면 전체 0.708 [0.675, 0.739], 도심 0.91, 농경지 0.60 → 검증 단위가 결론을 뒤집음
5. 과거 침수 근접도(2019년 이전 흔적만) 기준선: 0.533 / 0.568 — L1 과 비슷한 수준
6. 개념 불일치: 위험지수(H·E·V·D)의 등급을 침수 발생(hazard 결과)으로 캘리브레이션. E·V·D 는 피해 자료 검증 없음
7. 재현성: 9/16 이후 HEAD 재실행 없음, 리팩터 커밋이 코드 구조 변경
