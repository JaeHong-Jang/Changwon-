# Q1 심사 시뮬레이션 (Claude critic 서브 에이전트, 2026-09-26)

> 원문 보고서를 옮김. 리더 확인 사항은 맨 아래 "리더 확인" 절.

**판정: 반려(현 원고 기준). 조건 충족 시 REVISE 경로 있음.**

총평: 사전 게이트 고정·탈락 보존·run_id 감사 가능성은 학생 연구로서 이례적으로 좋음. 그러나 현재 중심 주장("지형 모형 10사상 일관", "강수 축 역전")은 사실상 사상 1개 + 홀드아웃 관측 후 설계 + 전 격자 배경의 쉬운 판별 과제에 기대고 있어 NHESS·IJDRR 모두 현 형태로는 통과 어려움.

## 1. 저널별 판정

### NHESS — access review 단계 반려 또는 심사 후 거절
1. 홀드아웃 = 사실상 사상 1개: 2024-09-20 이 폴리곤 183/196, 양성 격자 1,254/1,267. RF 95% 구간은 사상 내 덩어리 재표본 폭일 뿐 사상 간 변동 미반영.
2. 쉬운 배경: 배경은 산지 포함 72,953 격자. 로지스틱 순열 중요도 경사 0.244, 다음 0.017. 경사 단독·HAND 같은 자명한 기준선, 평지·토지이용 제한 배경 평가 부재. 인구 거주 격자로 한정하면 양성 102개, 그 안에서 CDRI(H=RF) AUC 0.48.
3. post-hoc 설계: 특징 후보군이 홀드아웃 진단 뒤 정해짐. v1 선택 때 전체 unittest 가 홀드아웃을 읽음(prespec `v1_holdout_read: true`), v1 채점 뒤 v2 로 교체.
4. C2 신규성이 얇음: 격자 AUC = 객체별 AUC 의 격자 수 가중평균. 도심 폴리곤 면적 중앙값 280 m² ≪ 1,000 m²(10% 규칙) → 산술적으로 자명. 선행 Ozturk et al. 2021 (10.1007/s10346-020-01485-5).
5. CDRI·예보 확장이 원고를 흐림(예보 주 판정 1·2 미충족).

### IJDRR — 데스크 리젝 가능성 높음
1. DRR 연결고리 실패: CDRI 홀드아웃 AUC 0.34→0.39→0.48, TOP20 최소 중첩 9/20.
2. 모형이 맞히는 곳이 주로 무거주 농경지: 거주 구역 안 양성 102/1,267.
3. V 가 고령비율 하나, 피해·119 결과 검증 없음.
4. 정책·실무 함의 없는 기술적 민감성 모형 원고로 읽힘(일반 지식).

- **권고: (C) — A 를 척추로, B 는 하위 결과로 강등.** 중심 질문 "행정 침수흔적의 구성(유형×객체 크기)과 평가 단위가 지수 판정을 결정한다". L1 은 농경지형 사상(2006·2024-09·2025)에서 무너지고 도심 폴리곤에서는 0.910; 시 예상도(내수 L210)도 홀드아웃 0.450 → "내수용 지수를 외수·농경지 위주 인벤토리로 채점한 불일치" 가설이 강수 역전보다 방어하기 쉬움.

## 4. 최소 패키지 (필수 합계 약 8~12주)

| 우선 | 항목 | 기간 | 새 자료 |
|---|---|---|---|
| M1 | 어려운 음성·자명한 기준선: 경사 단독·상대고도 단독·HAND, 평지·토지이용 제한 배경, 도심/농경지 층화 AUC, 거주 구역 안 H 단독 AUC | 3~5일 | 불필요 |
| M2 | 사상 단위 보고: 유효표본 명시, 사상별 AUC 무작위효과 통합 | 2~3일 | 불필요 |
| M3 | 중첩 시간순 CV: 특징·하이퍼파라미터 선택까지 학습 창 안에서 | 1주 | 불필요 |
| M4 | 라벨 규칙·단위 민감도 격자 (any·1%·10%·50%·중심점·면적가중) + "격자 AUC = 객체 AUC 가중평균" 해석적 분해 | 1~2주 | 셀 축소 시 5 m DEM |
| M5 | 사전등록 다도시 재현: OSF/Zenodo 시각 기록, 도시 선정 규칙 고정. 서울은 2022 단일 사상이고 Lee et al. 2026 (10.1016/j.jhydrol.2026.135531) 과 겹침 → 다년 도시 필요 (예: 50110 9개 연도, 48270·50130 8개 연도), 전국 공통 입력만 사용 | 4~8주 | 필요 |
| M6 | 재현성: `-dirty` 없는 공식 홀드아웃 재실행, run_id 불일치 정정, 동결 연대표(P0-8), Zenodo DOI | 3~4일 | 불필요 |
| M7 | 원고 재구성: CDRI·예보는 논의 한 단락/부록 | 1~2주 | 불필요 |

있으면 좋은 것: HSR 사건 강우(B 유지 시 필수), 5 m DEM, SHAP/ALE, PU 학습, 적용 가능 영역 분석 (Meyer & Pebesma 2021, 10.1111/2041-210X.13650).

## 5. 종합

- 오늘 원고 채택 가능성: 두 저널 모두 10% 미만 (주관적 추정).
- M1~M7 + 다도시 재현이 C2 를 부분 재현하면 NHESS 40~55%, IJDRR 30~45% (대응 우선순위·보호 인구 변화까지 보이면).
- M1 에서 경사 단독이 RF 에 근접하면 B 폐기, A 만으로 버텨야 함.

쓰면 안 되는 표현: 전향적·사전등록 검증 / RF 가 게이트를 통과해 검증됐다 / 10사상·20년 일관 / ML 이 지침형 지수보다 우월 / 지침형 지수 일반이 역전 / 강수 역전 원인 확정 / CDRI 가 우선순위를 식별 / 예보가 침수 예측을 개선 / 도심 침수 88% 소실(홀드아웃 57개 한정 없이) / 위치 모형이 거주 지역에서 잘 맞힘.

미해결 질문: 경사 단독 AUC와 거주 구역 안 H 단독 AUC (B 존폐), 2006·2024-09·2025 침수가 같은 낙동강 범람원 농경지에 몰려 있는지, 개발 인벤토리 토지이용 구성, 시 침수예상도(L210)가 과거 흔적을 보정에 썼는지(순환).
