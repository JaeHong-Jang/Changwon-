# 좌표 입력 안내 — 40개 지점

> 이 작업이 끝나면 P2 의 마지막 두 노드(`h03_stations`, `h03_pump_stations`)가 열리고
> Layer 1 로 넘어갈 수 있다. 대략 40분 걸린다.

## 왜 손으로 하나

지오코딩 API(V-World)는 약관에 **"별도의 저장장치나 데이터베이스에 저장할 수 없다"**
고 되어 있다. 우리는 좌표를 파일로 저장해 파이프라인 입력으로 고정해야 하므로 맞지 않는다.
게다가 하네스가 이미 `h03_pump_stations` 의 통과 조건으로 **"지도에서 육안 검수"** 를
요구하므로, 자동 지오코딩을 해도 어차피 40개를 사람이 봐야 한다.

## 채울 파일 2개

| 파일 | 행 | 내용 |
|---|---:|---|
| `data/external/pump_stations_geocoded.csv` | 9 | 배수펌프장 (주소 있음 — 제일 쉽다) |
| `data/external/stations.csv` | 31 | 강수 29지점 + 수위계 2지점 |

Excel 로 열어도 되고 VS Code 로 열어도 된다. **인코딩은 UTF-8 (BOM 포함)** 으로 저장한다.
Excel 은 그대로 저장하면 유지된다.

## 채우는 방법

1. **카카오맵**(https://map.kakao.com) 또는 **네이버지도**(https://map.naver.com) 를 연다
2. `address` 또는 `hint` 열의 내용을 검색창에 붙여 넣는다
3. 찾은 위치에서 **마우스 오른쪽 클릭 → "이 위치의 정보"** (카카오맵) 또는
   **오른쪽 클릭 → "좌표 복사"** (네이버지도) 로 위경도를 확인한다
4. `lat`(위도, 35.x), `lon`(경도, 128.x) 에 적는다 — **소수점 5자리면 충분**하다 (약 1m)
5. `source` 에 어떻게 찾았는지 적는다: `카카오맵` / `네이버지도` / `시제공`
6. 지도에서 눈으로 확인했으면 `reviewed` 를 `N` → `Y` 로 바꾼다
7. 애매했으면 `note` 에 남긴다 (예: "정확한 우량계 위치 불명, 주민센터 건물 기준")

### 위도·경도를 헷갈리지 않는 법

창원은 **위도 35.x, 경도 128.x** 다. 숫자만 봐도 구분된다.
`lat` 칸에 128 이 들어가 있으면 뒤바뀐 것이다 (검사기가 잡아준다).

## 지점 유형별 요령

**펌프장 9개 (가장 쉬움)** — 주소가 정확히 있다. 주소를 그대로 검색하면 된다.

**행정동·읍면 18개** — `hint` 에 "○○동 주민센터"라고 적어뒀다. 주민센터를 찍으면 된다.
⚠️ **주의**: 이건 실제 우량계 위치가 아니라 **그 동의 대표 지점**이다.
동 하나가 수 km 에 걸치므로 100m 격자 분석에서 오차가 된다.
`note` 에 "동 대표점 근사" 라고 적어두면 나중에 한계를 기술할 때 쓴다.

**공공시설 11개** — 성산구청, 진해구청, 마산소방서, 동부도서관, 진해물재생센터,
국방연구소, 팔용농산물(도매시장) 은 이름 그대로 검색하면 나온다.

**"○○민원" 4개 (소계민원·삼귀민원·의안민원·화천민원)** — 이름이 줄임말이다.
`소계동 주민센터`, `귀산동`(삼귀), `의안동`, `화천동` 으로 검색해본다.
못 찾으면 `lat`/`lon` 을 비워두고 `note` 에 "확인 불가" 라고 적는다.
**억지로 채우지 않는 것이 낫다** — 좌표 확보율이 90% 미만이면 하네스가 알아서 막는다.

**수위계 2개 (차룡8교·연덕교)** — 교량이다. 다리 이름으로 검색하고,
안 나오면 하천명과 함께 검색한다 (예: "차룡교 창원").


## 주소가 지도에서 안 나올 때 (펌프장 9개)

원본 CSV 의 주소는 **도로명·지번이 섞여 있고 일부는 지도 검색이 안 된다.**
`차룡단지로 208` 처럼 도로는 실존하는데 그 번지가 없는 경우가 있다.

### 순서대로 시도한다

1. **띄어쓰기·'동' 을 보정해서 다시 검색**
   - `신촌동86` → `성산구 신촌동 86`
   - `용원1111-12` → `진해구 용원동 1111-12` (원본에 '동' 이 빠져 있다)
   - `봉암공단 1길 34` → `봉암공단1길 34`
2. **지번주소로 바꿔 검색** — 9개 중 5개는 원래 지번주소다
3. **시설명으로 검색** — `팔용배수장`, `봉암펌프장` 처럼 공공시설은 지도에 등록돼 있을 수 있다
4. **인근 지형지물로 좁히기** — `마산항 제2부두`(구항), `마산 서항지구`(서항1·2), `차룡단지`(팔용)
5. **그래도 안 되면 비워두고** `note` 에 "주소 확인 불가" 라고 적는다

### 더 쉬운 길 — 공공데이터포털 표준데이터

전화번호 · 설치년도 · 설치목적` 컬럼이 있다. 창원 분이 포함돼 있으면 9개를 한 번에 해결한다.

## 다 채우고 나서

```bash
python -m src.data.check_coordinates
```

이 검사기가 아래를 잡는다 (실제로 시험해서 다 잡히는 것을 확인했다):

| 실수 | 잡히는 방식 |
|---|---|
| 위도·경도를 바꿔 적음 | "위도 128.6 이 창원 범위 밖 (바꿔 적은 것 같다)" |
| 엉뚱한 곳 (서울 등) | "좌표가 창원시 경계 밖이다" |
| 복사·붙여넣기로 같은 좌표 중복 | "좌표 (…) 가 여러 지점에 중복: A, B" |
| reviewed 를 Y 로 안 바꿈 | "reviewed=N 인 행 n개" |

`문제 없음` 이 나오면 알려달라. `h03_stations`·`h03_pump_stations` 구현을 이어서 하겠다.
